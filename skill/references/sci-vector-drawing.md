# 科研 & 矢量绘图参考

做**科研图表**、**原理图 / 机制图 / 通路图**、**任意矢量图形**时把这份当规范查。

它回答两件事：

1. **科研图怎么画才规范**（选型 / 统计量 / 坐标轴 / 字号线宽 / 配色 / 多面板 / 图注）；
2. **矢量图形怎么画才保真**（矢量优先、原语四件套、波形、具象图形、机制图、投稿导出）。

> 与 [design-recipes.md](design-recipes.md) 第 8.3 / 9 / 10 节分工：那边讲「一般 PPT 的图表与示意图」，**这份讲「科研 / 投稿 / 矢量的硬规范」**，冲突时以本份为准（更严）。
> **姊妹篇**：[vector-playbook.md](vector-playbook.md)（矢量绘图用法手册）——讲「矢量能力有哪些、什么时候用、用在哪、用多少、怎么用才高级」。**本份偏「科研图的硬规范」，那份偏「矢量能力的用法与用量」。**
> **画具体领域原理图**（Transformer / DNA / 病毒 / 电路 / 波形 / 拓扑 …）去 [diagram-atlas.md](diagram-atlas.md)（跨领域原理图图谱）。
> 字段的**唯一权威**是 [element-schema.md](element-schema.md) 第 8 节（chart 专节）。本份给的是「怎么用才规范」，不是字段清单。

## 一、落笔者就是你：直接照本规范画图

核心没有「软件侧替你把自然语言翻译成画布元素」这一层——**把元素 JSON 写出来、交给 `api.insert` 落盘的就是你自己**。所以下面的规范不是给谁看的参考，而是**你落笔时必须遵守的硬规则**：

| 事实 | 你要怎么做 |
| --- | --- |
| **画图的人和懂规范的人是同一个** | 没有中间层替你兜底——选型 / 统计口径 / 坐标轴 / 配色全靠你落笔时写对 |
| **每个类型都有 `modelNote`** | `api.element_types()` 返回每个类型的易错点 / 必填项提示，**写该类型前先读它**；字段定义查 [element-schema.md](element-schema.md) |
| **能力已经够全** | 86 个 shape 预设 / `path` 任意轮廓 / `connector` / 20 种 chart（含统计层）/ 300·600 DPI / PPTX 矢量优先 / SVG 真矢量**都在**——画不好是规范没用对，不是能力不够 |

**结论**：与其纠结用什么图形能力，不如**把下面的规范逐条落成字段**。本份讲的就是这些字段该怎么写。

## 二、科研绘图规范

### 2.1 图表选型（`props.kind`，共 20 种）

| 要表达 | kind |
| --- | --- |
| 类别间**比较** | `bar`（竖，多系列默认 `grouped` 并排）/ `hbar`（横，类目名长时用横） |
| 随时间 / 序列的**趋势** | `line`（`smooth:true` 平滑）/ `area` |
| 构成随时间变化 | `stackedArea` |
| **构成 / 占比** | `pie` / `donut`（`innerRadius` + `centerText`） |
| 层级对比 | `rose`（半径 ∝ √值） |
| 多指标**综合评分** | `radar`（`radarFill`） |
| 两类变量的**相关** | `scatter`（x 取数值列） |
| 三变量（x / y / 大小） | `bubble`（x、y、尺寸三列） |
| 转化 / 递进 | `funnel`（`funnelGap`） |
| 单指标完成度 | `gauge` / `progress` |
| **样本分布** | `box`（箱线，1.5×IQR）/ `violin`（小提琴） |
| **频数分布** | `hist`（`bins` / `density` / `kdeCurve`） |
| **累积分布** | `ecdf` |
| **均值 ± 不确定性** | `errorbar`（行 = `[名称, 均值, 误差]`） |
| **矩阵 / 相关性 / 热力** | `heatmap`（`heatColors`） |

**数据模型（读法要对）**：

- 常规图：`rows` 每行一条，**首列类目名，第 2 列起每列一个系列**（3 列以上才有多个系列，系列名用 `seriesNames` 覆盖）。
- **统计图形**（`box`/`violin`/`hist`/`ecdf`/`errorbar`/`heatmap`）走另一套读法：**首列是分组名**（同名自动合并），该行其余数值单元格全部算这组的**样本**——长表 `[["A",3.1],["A",3.5],["B",4.2]]` 与宽表 `[["A",1,2,3],["B",4,5,6]]` 等价。
- `errorbar` 读 `[名称, 均值, 误差]`；`heatmap` 首列非数值即行名，其余数值列构成矩阵。
- 散点 / 气泡：**首列是数值 x**（首列全文字则视为分组列自动跳过）；气泡再一列是尺寸。

### 2.2 统计量语义：误差棒 / 显著性 / 拟合

- **误差棒 `errorType`**：`none` / `sd`（标准差）/ `sem`（标准误）/ `ci95`（95% CI，`t(n-1)×SEM`）。由**重复样本**自动算 `mean ± 误差`，仅在柱 / 条形 / 折线 / 面积 / 箱 / 小提琴且确有重复样本时生效。**选择要跟图注口径一致**，不能图上一套、说明里另一套。
- **显著性 `compare`**：逗号 / 分号 / 换行分隔。写法三种：`A-B`（**自动 Welch t 检验**）、`A-B:0.008`（手填 p）、`A-B:***`（手填星号）。不显著自动标 `n.s.`，样本不足 / 方差为 0 标 `n.d.`。
  - `sigCorrect`：`none` / `holm`（Holm–Bonferroni **自动**校正；手填 p / 星号不参与校正）。多组两两比较时用 `holm` 并在图注注明。
  - ⚠️ **`hbar` 不画显著性括号**——要显著性就别用横向条形图。
- **拟合 `fitType`**：`none` / `linear` / `quad` / `cubic` / `exp`，用于散点 / 气泡 / 折线 / 面积。
  - **方程与 R² 默认已自动标注**（`fitShowEq:true` / `fitShowR2:true`，R² 取 3 位小数）——**不要重复手写进 title**；要关就改 false。

### 2.3 坐标轴与刻度规范

- **普通柱 / 条形图：纵轴从 0 起**（`maxValue:0` 时走 `niceMax()` 取整）。
- **统计图形默认按数据范围取刻度、不强行从 0 起**；要强制包含 0 就写 `zeroBase:true`。
- **散点 / 气泡的 x、y 目前都用 0 基准 `niceMax()`**——数据集中在高位时图会偏空，属已知短板；必要时手动写 `minValue` / `maxValue` 收口。
- **坐标轴标题必须带量纲 / 单位**：写 `xTitle` / `yTitle`（如 `xTitle:"时间 (h)"`、`yTitle:"吸光度 (a.u.)"`）。`hbar` 下两者都横排。
- **论文常规样式**：直方图 / ECDF 写 `axisBox:true` 画四周封闭坐标框。
- 刻度段数 `gridCount`（默认 4，1–12）；另可用 `minValue` / `maxValue` 手动收口。

### 2.4 字号 / 线宽 / 留白下限

| 项 | chart 字段 | 幻灯片内 | 投稿 / 打印稿 |
| --- | --- | --- | --- |
| 标题 | `titleSize`（默认 17） | ≥ 14px | ≥ 8pt |
| 刻度 / 轴标 / 图例 | `fontSize`（默认 12）+ `labelColor` | ≥ 11px | ≥ 7pt |
| 数值标签 | `valueColor` | ≥ 10px | ≥ 6pt |
| 数据线 / 坐标轴 | `lineWidth`（默认 2.5）/ `axisColor` | ≥ 1px | ≥ 0.75pt |
| 拟合线 | `fitWidth`（默认 2） | ≥ 1.5px | ≥ 1pt |

- 同一张图内**同类元素字号必须一致**；数值统一小数位与单位（`valueFormat`：`fixed1`/`fixed2`/`thousand`/`percent`/`compact`）。
- 斜率 / 单位写法统一用国际符号（`mol/L` 而非 `M`，除约定俗成外）。

### 2.5 配色：色盲 + 灰度双保险

- 默认 `palettePreset:"nature"`（期刊低饱和）；也支持 `""`（自定义 `palette`）。
- **色盲敏感 / 多系列靠颜色区分** → `palettePreset:"okabe"`（Okabe-Ito 色盲友好）。
- **黑白印刷 / 灰度投稿** → 出 `palettePreset:"grey"` 版本，或改用**形状 + 纹理**区分系列（不要只靠颜色）。
- 热力图色阶 `heatColors`：`viridis`（默认）/ `blue` / `red` / `green` / `grey` / `diverging`（以 0 为中心双向发光）。
- 文字与底色对比度 **≥ 4.5:1**；暗底页要把 `titleColor` / `labelColor` / `valueColor` / `gridColor` / `axisColor` 一并改成浅色。
- **一张图最多 3 个语义色 + 中性色**；同色系靠深浅表达层级。

### 2.6 多面板拼版（a / b / c）规范

- **每块面板必须有编号**（`(a)` `(b)` `(c)`…），位置固定（左上 / 右上），**全图统一**。
- 各面板**尺寸、间距、四周留白一致**，居中排布。
- **配色 / 字号 / 线宽 / 图例样式跨面板统一**（「像一套图」的关键）。
- 共享轴时可省略重复轴标，但要在图注说明；面板内小标题 / 单位不能省。

> **具体怎么拼**（版式选择 / 坐标几何 / `gap` 与留白 / (a)(b)(c) 编号摆放 / 与 chart 混排 / 常见坑）见 [vector-playbook.md](vector-playbook.md) **第六节「多子图 / 面板拼版」**。

### 2.7 图注与图表要素清单

出图前逐项自检：

- [ ] 标题是**结论式**（不是「图表 1」）
- [ ] `xTitle` / `yTitle` 带**量纲 / 单位**
- [ ] 多系列有图例（**单系列 2 列数据、或条目 > 12 条时图例会被自动隐藏**，别白写）
- [ ] 误差棒口径写清（sd / sem / ci95）
- [ ] 显著性用 `*` / p 值 / `n.s.`，与图注一致；多组比较用了 `holm`
- [ ] 拟合有方程与 R²（默认已自动标；关掉过就补进图注）
- [ ] 样本量 n 写在图注
- [ ] 配色方案说明（是否色盲友好 / 是否有灰度版）
- [ ] 多面板编号 (a)(b)(c)
- [ ] 单位、小数位、坐标范围一致

### 2.8 常见科研绘图错误清单（改稿优先查）

- 普通柱图纵轴不从 0 起 / 截断柱。
- 误差棒口径与图注不符；画了误差棒却不说明是什么。
- 只标 `**` 不标 `n.s.`；显著性括号不与类别中心对齐；**给 `hbar` 配了显著性（画不出来）**。
- 坐标轴无量纲 / 无单位；刻度小数位不统一。
- 画了拟合线却关掉了 `fitShowEq`/`fitShowR2` 又没补图注。
- 多面板缺 (a)(b)(c)；或各面板字号线宽不一致。
- 靠颜色区分系列却无灰度 / 色盲兜底。
- 散点 / 气泡把类目当 x，或数据在高位却因 0 基准显得又空又挤。
- 图例条目 > 12 条被自动隐藏，或单系列却指望有图例。

## 三、矢量绘图规范

### 3.1 矢量优先原则

**凡是「图形 + 文字 + 连线」能摆出来的图，一律用矢量原语画**，不要用图片替代。

- 矢量 = 进 PPTX 仍是可编辑真矢量 / 原生图表 / 原生表格、改色改位只动一个字段、放大不失真、能导出真矢量 SVG。
- **必须矢量的**：原理图 / 机制图 / 通路图 / 流程图 / 架构图 / 拓扑图 / 数据图 / 波形 / 符号 / 标注。
- **只能是位图的**：真实照片、截图、外部素材（走 `image` + `api.import_asset(path, [文件...])`）。

### 3.2 矢量原语四件套（注意真实默认值）

| 原语 | 适合画 | 关键点（**别踩默认值**） |
| --- | --- | --- |
| `shape` | 装置外壳、容器、细胞 / 组织块、箭头、圆角框；**86 个 OOXML 预设**（flowChart 族 / 箭头族 / 星形 / 标注 / 圆柱 / 立方体…） | 填充字段是 **`style.background`**（写 `fill` 无效）；**默认无边框（`borderWidth:0`）**，新建就是干净色块，**要框线必须显式写 `borderWidth`（+ `borderColor`）** |
| `path` | 自由线稿：曲线、螺旋、波形、通路、自定义符号 | 自写 `props.d`（局部坐标 0..w / 0..h）；**避免弧线命令 `A`/`a`**（PPTX 会回退成截图、丢可编辑性，改用多段 `C`）；默认无边框，**线稿必须显式写 `borderWidth > 0`** 才可见 |
| `connector` / `shape:"line"` | 连线、箭头、引线、误差棒、坐标轴、比例尺 | 只靠描边显形，**必须显式写 `borderWidth`（1~1.5）**；`connector` 两端写 `props.from` / `props.to`（元素 `name` 或坐标），`route`=straight/elbow/curve |
| `chart` | 20 种统计图（见第二节） | 数据来自 `props.rows`；PPTX 里默认走**原生图表**（可编辑） |
| `text` | 正文、公式、坐标标签、图注 | 公式写 `$…$` / `$$…$$`；PPTX 里仍是可编辑真文本 |
| `table` | 实验数据表、参数表 | 无表题字段，要表题就在上方另起 `text` |

### 3.3 科研波形（自写 `props.d`）

核心**没有「常用波形」面板**——编辑器里的那套预设在这里不存在，要把波形落成 `path`，必须**自己在 `props.d` 里写等价路径**（用多段 `C` 拟合，**避开弧线 `A`**）。常画的波形形态与拟合目标：

`sin` / `cos`（正弦 / 余弦振荡）、`gauss`（高斯峰）/ `lorentz`（洛伦兹峰）、`decay`（指数衰减）/ `damped`（阻尼振荡）、`sigmoid`（S 形）/ `tanh` / `step`（阶跃）、`parabola` / `log` / `linear`

> 用途：信号波形、响应曲线、势阱、分布示意、传递函数——**不要用一堆散点去凑曲线**。

### 3.4 具象图形：优先图标库，其次自绘或用图片

核心**内置矢量图标库**（1800+ 图标，36 组）：`api.icon_search("神经元")` 找 id → `api.icon_insert(path, id, x=, y=, size=120, color="#c0392b")` 插成**可编辑 `path`**（单色可换色；多色插成 `group` 容器 + 分层成员）。整组浏览用 `api.icon_groups()` / `api.icon_list(group)`。要表现具象物件（网络设备 / 电子元件 / 化工设备 / 液压元件 / 分子细胞 / 实验器材…）时，按下面四条走：

1. **优先 `icon_search` + `icon_insert`**：图标库覆盖 draw.io 几何 / 流程 / 器件、Bioicons 分子 / 细胞 / 器材 / 动植物、Apollon UML / 流程图；先搜关键词，命中就用现成图标，最省事也最像。
2. **图标库没有的，用 `shape` 预设**：86 个 OOXML 预设覆盖一批通用图形（箭头族 / 流程图族 / 星形 / 标注 / 圆柱 / 立方体…），不少部件用现成预设就能表达。
3. **预设也没有就 `path` 自绘**：简单轮廓 / 几何体 / 常规符号，写 `props.d` 自己画成具象图形，**不许退回空白矩形**；复杂到画不动的，才退回最简形状 + `text` 标注，并在交付说明里写明替代符号。
4. **图片型图标走 `image`**：手头已有图标位图 / SVG，用 `api.import_asset(path, [文件...])` 导入，再把返回的 `relPath` 写进 `props.src` 当 `image` 用。

> **判据**：凡节点 / 部件代表**真实物件或领域标准符号**，就要画成具象图形或贴对应图标图片；**把具象物件画成空白矩形 = 缺陷**。

### 3.5 机制图 / 通路图构图

1. **先分层再放节点**：每层一个大 `rect`（`style.background` 极浅底）当层容器，层高于层间距。
2. 节点用 `shape` + **同坐标 `text`**（图文分离；居中用 `textAlign:"center"` + 显式 `verticalAlign:"middle"`，别靠挪 `y`）。
3. 关系用 `connector`（端点写节点 `name`，`route:"elbow"` 走正交折线）；激活 / 抑制分别用**实线箭头 / 平头线**（`arrowEnd:false`）。
4. **配色不过三**；核心通路 `accent` 描边，次要 `muted` + `strokeDash:"dash"`。
5. 连线数 ≤ 节点数 × 1.5，其余靠包含关系暗示；**节点数每图 ≤ 12**。
6. 图形区占页 ≤ 65%，一侧留文字说明区。

### 3.6 导出与投稿

- **位图**（可透明、高 DPI）→ `api.export(path, "png", dpi=300, transparent=True, pages=...)`：`dpi` 取 `300`（投稿默认）或 `600`，按 `pages` 选页。
- **真矢量图** → `api.export(path, "svg", pages=...)`（文字 / 图片 / 路径 / 连线为矢量，其余按 dpi 内嵌）。
- **可继续编辑的演示稿** → `api.export(path, "pptx")`（**默认矢量优先**）：图表 → 原生 PPTX 图表、表格 → 原生表格、代码 / 公式 → 逐行真文本 + 图元重建。
  - ⚠️ **会回退成截图的情况**：渐变 / 投影 / 发光 / **元素级**不透明度（`opacity` / `fillOpacity`）/ 模糊 / **`path` 弧线命令**，或该元素标了 `props.rasterMode:"raster"`（稳截图）。**正文元素要保矢量，就避开这些效果**；装饰回退无伤大雅。（`rgba()` 颜色自带 alpha 会原生写成 `a:alpha`，不算回退。）
- **无自动文字转曲**：投稿若要求转曲 / 字体嵌入，需手工处理。
- 交付时说明：**矢量保真看 SVG / PDF**（导出细节与依赖见 [export.md](export.md)）。

## 四、落地检查清单

**画科研 / 矢量图时：**

- [ ] 图型选对了吗（对照 2.1）
- [ ] 误差棒口径、显著性、拟合方程与 R² 都交代了吗（`hbar` 别配显著性）
- [ ] 普通柱图纵轴从 0 起；统计图形按数据范围（需要才 `zeroBase`）
- [ ] `xTitle` / `yTitle` 带单位；刻度取整；直方 / ECDF 用 `axisBox`
- [ ] 配色 nature / okabe / grey 选对；有对比度与灰度兜底
- [ ] 字号 / 线宽在下限之上；同类元素一致
- [ ] 多面板有 (a)(b)(c) 且尺寸 / 间距 / 配色统一
- [ ] 原理图 / 波形 / 符号走矢量原语，没用图片 / emoji 凑
- [ ] 连线用 `connector`、走正交；**shape/path 线稿显式写了 `borderWidth`**；`path` 没用弧线 `A`
- [ ] 图注要素齐（n、口径、显著性、R²、配色说明）
