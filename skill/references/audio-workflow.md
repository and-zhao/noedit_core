# 音频插入工作流（合成 / 素材 → 落入工程 → 插入页面）

本文件给**需要给页面配音的 Agent** 用：何时配音、怎么合成、怎么把音频安全地落进 NoEdit Core 工程并在各导出格式里正确呈现。

## 核心约束

1. **`props.src` 只能写工程内 `assets/` 的相对路径**（如 `assets/p1.mp3`）。**不许写 http(s) 外链**——导出件必须离线自包含。
2. **默认不加音频**：先问用户要不要配音、要哪种（讲稿旁白 / 背景乐 / 音效），不要自作主张全篇铺满。
3. **音频条会显示在画布上**：排版时把它当一个普通小元素摆放，**不要压住正文**；低调做法是放页脚角落或与底色同色。
4. 一页建议 **≤ 2 条**（讲稿 + 背景乐），多了互相打架。

## 何时值得配音

| 场景 | 建议 |
| --- | --- |
| 「发给别人自己看」的无人讲解 PPT | **每页讲稿旁白**（最有价值） |
| 发布会 / 氛围类 | 封面或结尾一段**背景乐** |
| 教学 / 操作演示 | 关键步骤**音效或解说** |
| 现场有人讲演的汇报 | **不配**（现场讲解 + 旁白会互相干扰） |

## 标准动作（五步）

### 1. 写讲稿文本

每页讲稿 = 该页内容的**口语化串讲**，不是页面文字的朗读版：
- 90–150 字 / 页（约 30–50 秒，语速 220–260 字/分钟）；
- 开头一句点题（「这一页讲的是……」），结尾一句承接下一页；
- 数字、专有名词要写**读法**（「3910 亿美元」写成「三千九百一十亿美元」视 TTS 能力而定，读不好的 TTS 就用汉字读法）。

### 2. 合成音频（agent 自带 TTS / 云端语音接口时）

**提示词 / 参数模板**：

```
文本：<讲稿文本>
语言：<zh-CN / en-US / ja-JP …，与页面语言一致>
音色：<按内容气质选：商务汇报→沉稳中性；教学→清晰亲切；发布→有张力>
语速：<0.9–1.1 倍，默认 1.0>
情感/风格：<平稳 / 热情 / 严肃，按主题>
输出格式：<mp3 优先；wav 也可（大）；44.1kHz 单声道即可>
```

**注意**：
- TTS 合成失败或没接口 → **跳过配音**，不要留一个无声的占位音频；
- 背景乐不能合成时不要硬用 TTS 念白充当——宁缺毋滥；
- 合成后**听不了就检查时长**：音频秒数和讲稿字数对不上（如 200 字只合成出 3 秒）说明截断了，重合成。

### 3. 落入工程

```python
# 拿到文件路径
rec = api.import_asset(path, [r"D:\tts\p1.mp3"])["imported"][0]

# 拿到字节 / dataURL → UI 通道
# POST /api/call {"method":"upload_asset","args":["p1.mp3","data:audio/mpeg;base64,…"]}
```

### 4. 插入 audio 元素

```python
api.insert(path, {
    "type": "audio",
    "name": "页1-讲稿",
    "x": 64, "y": 650, "w": 320, "h": 44,       # 页脚角落，不压正文
    "props": {
        "src": rec["relPath"],                    # assets/p1.mp3
        "title": "第 1 页讲稿",
        "startAt": 0,                             # 进入该页后第几秒开始播
        "autoplay": True,                         # 进页自动播
        "loop": False,
        "controls": True,                         # 显示原生控制条
        "volume": 1.0,
    },
}, page_index=0)
```

### 5. `startAt` 排布（一页多条时）

| 组合 | 排法 |
| --- | --- |
| 讲稿 + 背景乐 | 讲稿 `startAt=0`；背景乐 `startAt=2`（讲稿起头后渐入），`volume=0.3`、`loop=True` |
| 多条音效 | 按 UI 里事件顺序错开：0s / 4s / 8s… |
| 封面氛围乐 | `startAt=0` + `loop=True` + `volume=0.5` |

## 导出行为（给用户交代用）

| 格式 | 行为 |
| --- | --- |
| **HTML** | 真播：页面滚进视口后 `startAt` 秒自动开始，离开视口暂停；`controls=False` 时点击音频条切换播放 |
| **PPTX** | **真嵌音轨**：PowerPoint 放映可直接播；不播时显示音频条图形（喇叭 + 名字） |
| **PDF / PNG / SVG** | 静态音频条（喇叭图标 + 名字），无声 |

## 常见反面模式

- ❌ `props.src` 写成 `https://…` 外链；
- ❌ 没问用户就全篇铺配音；
- ❌ TTS 直接朗读页面标题 + 正文原文（该写口语化讲稿）；
- ❌ 一页塞 3 条以上音频互相打架；
- ❌ 音频条压在正文 / 图表上；
- ❌ 合成失败留无声占位；
- ❌ 忘了 `autoplay=True`，导出后用户得手动点每一页才响。

## 与 UI 的配合

本地 UI 左栏「元素」面板底部有**音轨面板**：本页每条音频一行，块的位置就是 `startAt`，**拖动块即可改它在第几秒开始播放**；点音频名字可选中该元素。改完刷新即生效。
