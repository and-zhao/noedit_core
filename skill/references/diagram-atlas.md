# 跨领域原理图图谱（Diagram Atlas）

**这份解决什么**：原理图（架构 / 流程 / 结构 / 通路 / 机制 / 装置 / 波形 / 拓扑）画得「简陋、缺细节、不专业」。**不是为了限制题目，而是给你一套「结构语法 + 领域图种库」**，让你画得出、画得对、画得细。

> 分工：[vector-playbook.md](vector-playbook.md) 讲「矢量能力何时用 / 用多少 / 怎么高级」；[sci-vector-drawing.md](sci-vector-drawing.md) 讲「科研图的硬规范」；**本份讲「各领域的图长什么样、由什么构成、怎么摆」**。字段权威仍是 [element-schema.md](element-schema.md)。

> **本核心内置矢量图标库**（1800+ 图标，`api.icon_search` 找 / `api.icon_insert` 插），所以文中凡标 **〔具象〕** 的部件，都按下面四条走：① 先 `api.icon_search` 搜关键词，命中就 `icon_insert` 插成可编辑 `path`；② 图标库没有的，看 `shape` 的 86 个预设能不能表达；③ 预设也不够就 `path` 自绘（`props.d`，避开弧线 `A`）；④ 手头有图标位图 / SVG 就用 `api.import_asset` 导入、当 `image` 用。**把具象物件画成空白矩形 = 缺陷。**

## 零、通用画法骨架（任何原理图先过这节）

### 0.1 画任何原理图的六步

1. **定语义**：这张图要说的**唯一结论**是什么？（说不出一句话 → 还没想清，别动手）
2. **选母题**：把它归到第一节 14 个母题里的哪一个 / 哪几个组合。
3. **定原语**：节点 = `shape`；连线 = `connector`；曲线 / 自定义轮廓 = `path`；数据 = `chart`；所有文字 = `text`；成组 = `group`。
4. **排版栅格**：画布 1280×720、四周留白 60；同类元素**等宽等高**、边线落在**同一组 x/y**；`gap` 统一（24 / 40）。
5. **语义配色**：按 0.3 字典上色；**一张图一个强调色**。
6. **标注与图注**：每个节点有标签；关键连线标含义（实/虚/箭头）；必要处加**单位 / 图注 / 局部放大**。

### 0.2 图元选择总则

| 要画的东西 | 用什么 | 备注 |
| --- | --- | --- |
| 方块 / 圆 / 圆角卡 / 圆柱 / 云 / 星 / 多边形 / 箭头块 | `shape` | 86 预设，**写 `props.shape` 名**；默认无边框，要框显式写 `borderWidth` |
| 任意曲线 / 螺旋 / 轮廓 / 波形 / 自定义符号 | `path` | 自写 `props.d`（局部坐标）；**避弧线 `A`**（回退截图） |
| 任何箭头 / 连线 / 引线 / 关系 | `connector` | **不要用 shape 的线/箭头拼**；端点绑元素名 |
| 数据、分布、趋势、构成、矩阵 | `chart` | 20 种，PPTX 原生可编辑 |
| 所有文字 / 公式 / 编号 / 图注 | `text` | **不与 shape 混写**，同坐标 + 居中 |
| 参数表 / 结果表 | `table` | 科研用三线表 |
| 一组要整体移动 / 复制的元素 | `group` | 分层容器、子图、图例块 |
| **具象物件**（设备 / 器件 / 分子 / 细胞 / 标准符号…） | `shape` 预设 / `path` 自绘 / `image`（导入图标图片） | **不许拿空白矩形冒充**（见开篇说明） |

### 0.3 语义配色字典（一图一套，全篇复用）

| 语义 | 表现 |
| --- | --- |
| 主数据流 / 主链路 | 主色**实线** + 实心箭头 |
| 控制 / 触发 / 时序 | 主色**实线**（可细一档） |
| 反馈 / 抑制 / 负向 | **虚线** + 平头（⊥）或灰色 |
| 外部 / 第三方 / 边界 | 灰框 / 虚线框 / 云形 |
| 存储 / 数据 / 库 | `can`（圆柱）或圆角矩形 + 浅底 |
| 强调 / 当前 / 焦点 | 强调色**填充**（其余中性灰） |
| 废弃 / 次要 / 历史 | 灰 + 降 `opacity` |
| 正向 / 增益 / 通过 | 主色或绿；负向 / 损失用**暖橙**（**避免红绿同用**，色盲不辨） |
| 不同类对象 | 用**同一色系的深浅**区分，而不是跳到无关色相 |

配色只准：**一个强调色 + 中性灰阶 + 最多一个语义色**。

### 0.4 十四大母题速查（「画什么」的语法）

| # | 母题 | 一句话 | 典型领域 |
| --- | --- | --- | --- |
| M1 | **分层堆栈** | 上下叠层，层间有接口 | 协议栈、网络、芯片、模型层 |

| M7 | **坐标系 / 曲线** | 轴 + 曲线 + 标注 | 波形、函数、谱、Bode、能带 |

## 一、通用母题库（详细做法）

> **图例**：文中 **〔具象〕** = 该处部件是**真实物件 / 领域标准符号**，要用 `shape` 预设 / `path` 自绘具象图形（或 `api.import_asset` 导入图标图片）表现，**不要用空白矩形**。

### M1 分层堆栈（Layer Stack）
- **用途**：协议栈、网络五层、芯片架构、软件分层、模型层堆叠、地质分层。
- **构成**：N 个**等高同宽**的层块，**垂直堆叠、左对齐**；每层左端固定放**层名**（如 L1–L5 / 应用层…），右侧放细节；**层间留 2–4px 缝**（或共用一条细线）。
- **原语**：每层 = `rect`（`borderRadius:4`，浅底 + 细边框）+ `text`；层间接口 = 细 `shape:"line"` 或 `connector`（不放箭头）表示「相邻层可通信」。
- **坐标骨架**：层宽统一（如 720），高统一（如 72），x 恒定，y 按 `y0 + i*(h+gap)`。
- **细节**：左侧留 8px 内边距放层号；不同层用**同色系深浅**递变（越上越浅）；把「本图重点那一层」用强调色。**层内可配领域具象图形**（协议栈 → 交换 / 路由意象；芯片 / 模型层 → 电路 / 模块意象；机房 → 机柜轮廓）——〔具象〕。
- **陷阱**：层高不一致 → 显廉价；层间箭头画成双向粗箭头 → 错（层间是**接口**不是数据流）。

### M2 流程链 / 管线（Pipeline）
- **用途**：编译流程、数据流水线、实验 SOP、工艺路线、审批流、算法步骤。
- **构成**：3–8 个节点**等距横向排列** + 节点间箭头；节点用 `flowChartProcess` 或 `roundRect`；判断点用 `diamond`（`flowChartDecision`），**从菱形分出两个带标签的分支**（是/否）。
- **原语**：节点 `shape` + 标签 `text`（同坐标居中）；箭头一律 `connector`（`route:"straight"`，`arrowEnd:true`）。
- **坐标骨架**：可用宽 1160，`n` 个节点 → 节点宽 `(1160 − (n−1)*gap) / n`；**Y 轴中线对齐**。
- **细节**：**编号**（①②③ 或 1/2/3）放节点左上角；分支标签（是/否、≥0/＜0）紧贴箭头；长流程**折成两行 S 形**，用 `elbow` 连接，别硬挤。
- **陷阱**：节点大小不一；箭头长度不等；菱形当普通节点用（它必须**有分叉**）；把连线画成图片。

### M3 循环 / 反馈回路（Loop）
- **用途**：控制回路（负反馈）、代谢循环（TCA/卡尔文）、PDCA、训练闭环、生态循环。
- **构成**：3–5 个节点围成**圆或方环**，顺时针箭头首尾相接；**反馈支线**从末端拉回起点（虚线，标「反馈/抑制」）。
- **原语**：节点 `shape`；环边 `connector`（`route:"curve"` 或折线）；反馈用**虚线**。
- **坐标骨架**：用**中心 + 极坐标**布点（4 点 = 上下左右，5 点 = 五角），保证视觉均衡。
- **细节**：环**方向统一**（统一顺时针）；反馈线**绕外侧**走，不要穿过节点；节点标签 + 一句动作（如「检测偏差」）。
- **陷阱**：箭头方向混乱；反馈线穿图；节点排成一行丢失「循环」语义。

### M4 树 / 层级（Tree）
- **用途**：目录结构、分类体系、进化树、组织架构、决策树、DOM/语法树、文件系统。
- **构成**：**根在上，逐层向下分叉**；同层节点**顶边对齐、等距**；父子用**折线（elbow）**连接。
- **原语**：节点 `shape`（叶可用小 `roundRect`）+ `text`；连线 `connector`（`route:"elbow"`）。
- **坐标骨架**：按**层定 y**、按**叶数定 x**（叶均分可用宽，父节点 = 子节点中点 x）。
- **细节**：进化树可把**枝长按差异**画；组织架构用**同级同色**；决策树在分支标条件。
- **陷阱**：父子连线用直线斜穿（应为正交折线）；同层不对齐；根不在正中。

### M5 网络 / 拓扑（Network）
- **用途**：通信组网（星/环/总线/网状/树）、计算图、依赖图、知识图谱、社交网络、神经网络结构、电路网表。
- **构成**：**节点 + 边**；边**可带方向（箭头）/ 权重（线宽或标签）**；核心节点居中放大。
- **原语**：节点**优先具象图形**——交换机 / 路由器 / 防火墙 / 云 / 服务器 / 终端的意象（`shape` 预设如 `cloud`，或 `path` 自绘，或导入图标图片）；实在画不动才退回 `shape`（服务器=`can`/`cube`，终端=`rect`，云=`cloud`）。边 `connector`。
- **坐标骨架**：先定**布局范式**——星形（中心 + 放射）、环（周向）、总线（一条横轴 + 垂直支线）、网格（行列）、力导向（手动均衡）。
- **细节**：**链路类型用线型区分**（实线=主链路、虚线=备份、点线=控制）；带宽/延迟标在线旁；**超 12 节点要分组**（用浅底 `rect` 圈出子网）。
- **陷阱**：连线交叉成网（用正交 + 分组化解）；节点无区分（同级同形）；忽略方向。

### M6 矩阵 / 网格（Matrix）
- **用途**：混淆矩阵、卷积核、注意力矩阵、热力图、相关性矩阵、像素阵列、对照表。
- **构成**：`m×n` **等大格子**紧排；行列有标题；**格子填色深浅表达值**。
- **原语**：格子 = `rect`（无缝或有 1px 缝）；行列标题 = `text`；**数据型用 `chart:heatmap` 更好**。
- **坐标骨架**：格子边长统一（如 40），间距 0 或 2；**行列标题居中于各自轴**。
- **细节**：**色阶**用单色由浅到深（别用彩虹）；对角线/极值格**描边强调**；加**色标（colorbar）**。
- **陷阱**：格子大小不一；用彩虹色阶（不可辨、不专业）；无行列标题。

### M7 坐标系 / 曲线（Coordinate）
- **用途**：时域波形、频域谱、传递函数 / Bode、能带 / 能级、势垒、函数图像、剂量-响应、相图。
- **构成**：**带箭头的 x/y 轴 + 曲线 + 关键点标注 + 单位**；多曲线用**线型 / 颜色**区分并给图例。
- **原语**：轴 = `shape:"line"`（**显式写 `borderWidth`**）+ 箭头，或 `connector`；曲线 = `path`（自写 `d`，正弦 = 多段三次贝塞尔）；纯数据曲线**优先 `chart:line`**；轴刻度 = `text`。
- **坐标骨架**：先画**坐标框**（原点 + 两轴），定好物理量范围，再把曲线坐标映射进去；**轴端要箭头**。
- **细节**：**周期数**画够（正弦 ≥ 2.5 个周期才像波）；标出**振幅 / 周期 / 峰值 / 半高宽**；虚线画参考线（均值线、阈值线、切线）。
- **陷阱**：轴无箭头、无单位、无刻度；曲线太扁或太陡（比例失真）；正弦画成圆弧拼接（应为平滑贝塞尔）。

### M8 环形 / 周期（Cycle）
- **用途**：细胞周期、产品生命周期、日月年周期、雷达能力、生物钟、圆环占比。
- **构成**：**圆环 + 周向分段 + 中心标签**；分段有色、有角度（角度即占比）。
- **原语**：`chart:donut` / `chart:rose`（数据型）或 `shape:"donut"`/`blockArc`（示意型）；分段标签 = `text`。
- **细节**：**分段时间按比例**，顺序顺时针；中心写总览；配色同色系；分段可配领域具象图形。
- **陷阱**：用饼图表示**不构成整体**的项目；角度与占比不符。

### M9 时间轴 / 阶段（Timeline）
- **用途**：项目计划 / 甘特、技术演化、病史、地质年代、里程碑、版本迭代。
- **构成**：**一条主轴**（横或竖）+ 刻度 + 事件节点（标签上下交错避免重叠）；甘特再加**条形块**。
- **原语**：主轴 = `connector` 或 `shape:"line"`；节点 = 小 `shape`（圆/菱形）；条形 = `rect`；文字 `text`。
- **坐标骨架**：**时间等比**（真时间轴）或**等距**（阶段轴）；甘特 y = 任务，x = 时间。
- **细节**：**今天 / 关键点**用强调色；**上下交错**放标签；标时间单位。
- **陷阱**：时间不等比却标了日期；标签互相压叠。

### M10 剖面 / 截面（Cross-section）
- **用途**：地质剖面、建筑剖面、器官 / 组织剖面、器件结构、电池 / 芯片叠层、管路。
- **构成**：**外轮廓 + 内部层 / 腔 / 结构**，各层**不同填充**；**标注引线**指向各部位。
- **原语**：外轮廓 = `path`（自由轮廓）或 `shape`；内部层 = `path` / `rect`；引线 = `connector` + `text` 标签。
- **坐标骨架**：先定**剖面矩形范围**，内部按「由外到内」分层，层厚按**真实比例**。
- **细节**：**比例尺**必给；引线**不交叉**；每层有名称 +（可选）尺寸；**剖的是真实物件就配具象图形**（器官 / 组织、器件 / 电池、泵阀管路…）——〔具象〕。
- **陷阱**：层厚随意（失真）；引线乱穿；无比例尺。

### M11 集合 / 交并（Set）
- **用途**：文氏图、范围重叠、逻辑关系、用户分层、条件交集。
- **构成**：2–4 个**半透明圆**部分重叠；交叠区标文字。
- **原语**：`shape:"circle"` + **半透明填充**（`fillOpacity`）；标签 `text`。
- **细节**：重叠区**看得见**（降低不透明度）；数量标在区域内。
- **陷阱**：超过 4 个集合（不可读）；不透明 → 交叠区被遮。

### M12 堆叠 / 比例条（Proportion）
- **用途**：预算构成、时间分配、成分比例、资源占比、进度。
- **构成**：**一条（或几条）横向条**，按比例分段、段内标名与百分比。
- **原语**：`rect` 分段（**首尾段圆角、中间段直角**才好看）或 `chart:bar` 堆叠；标签 `text`。
- **细节**：**同色系深浅**；百分比 + 名称都要；总长统一以可比。
- **陷阱**：段与段之间留缝（错，应紧贴）；颜色跳脱。

### M13 框内放大（Inset）
- **用途**：局部结构放大、细节强调、嵌入小图、宏观-微观对照。
- **构成**：主图 + **放大框**（同比例） + **两条引线**指向被放大区域。
- **原语**：放大框 = `rect`；内容 = 同 `shape`/`path` 结构；引线 = `connector`（**显式写宽度**）；放大框与主图**同配色**。
- **细节**：放大框**带边框**且与主图**视觉区分**（细蓝框）；两引线**平行**或对称。
- **陷阱**：放大内容与主图不一致；引线乱指。

### M14 对照 / 2×2（Comparison）
- **用途**：优劣对比、象限定位、方案对照、前/后、A/B。
- **构成**：**左右镜像**或**四象限**；中央可有分界线；**同结构同尺寸**才能比。
- **原语**：两个 `rect` 对照区 + `text`；象限 = 十字轴 + 四点定位。
- **细节**：**严格镜像对齐**；两方用**对比色**（蓝 / 橙，不用红绿）；每方标题 + 要点。
- **陷阱**：两边信息量不对等；缺坐标 / 缺轴标签（象限图必须有轴名）。

## 二、领域图谱（图种 → 构成骨架 → 原语 → 要点）

> **图例**：原语列里的 **〔具象〕** = 该部件是**真实物件 / 领域标准符号**，要用 `shape` 预设 / `path` 自绘具象图形（或 `api.import_asset` 导入图标图片）表现，**把具象物件画成空白矩形 = 缺陷**。

### A. 计算机 / 软件 / AI

| 图种 | 构成骨架 | 原语 | 关键细节 |
| --- | --- | --- | --- |
| **Transformer 架构** | 左侧输入 → 嵌入 → [+位置编码] → 多头注意力（Q/K/V 三叉）→ 残差+LayerNorm → FFN → [+残差] → 输出；右侧「×N 层」括号包住编码器块 | `shape` 块 + `text` + `connector`；残差用**绕行曲线**；`path` 画「×N」括号 | **残差是绕过子层的另一条线**（必须画，常被漏）；Q/K/V 从输入**分三叉**；「×N」用大括号 + 文字；层内**同色系** |
| **CNN** | 输入图像 → 卷积 → 激活 → 池化 → … → 全连接 → 输出；每个特征图用小方格阵列 | `shape` `rect` 叠成 3D 块 + `path`/方格 | 特征图用**多层错位矩形**表示通道；卷积核用**小方格 + 滑动箭头**；尺寸递减要体现 |
| **RNN/LSTM** | 横向展开的时间步 x₁…xₜ，每步一个单元 + **横向隐藏态箭头** + 向上输出 | `shape` 圆/块 + `connector` | **隐藏态横传**是关键；单元内画门控（输入/遗忘/输出门）用三个小色块 |
| **GAN** | 生成器 G → 假样本 ↘；判别器 D ←→ 真/假 → 真伪判定；虚线回传训练 | `shape` + `connector`；**虚线**表梯度回流 | 两条回传虚线（G、D 各一条）；真/假两路输入 D |
| **扩散模型** | 前向加噪链 x₀→x₁→…→x_T（噪声递增），反向去噪链 x_T→…→x₀ | 上下两条链 + 中间时间轴 | 前向箭头**递增噪声**，反向**递减**；用灰度递变表噪声 |
| **系统架构图** | 客户端层 / 网关 / 服务层 / 数据层（**分层堆栈 M1**）；层间调用箭头 | `rect` 分层 + `connector` + **具象**（网关 / 服务器 / 机柜 / 数据库 `can`） | **层次 + 同类服务并排**；数据层用 `can`；外部系统用**虚线框** |
| **微服务** | 网关 + 若干服务块 + 各自 DB + 服务间调用；注册中心在侧 | `roundRect` + `connector` + 〔具象〕服务 / 队列意象 | 服务**等大**；同步调用实线、异步消息虚线；配**消息队列**块 |
| **部署 / 云架构** | 区域框套可用区框套实例；负载均衡在入口 | 嵌套 `rect` 作边界 + 〔具象〕实例 / 部署节点 | **嵌套框表边界**（云/区/主机）；用 `cloud` 表外部 |
| **数据结构** | 链表（块 + 指针箭头）、数组（紧排格）、栈/队列（开口容器 + 元素）、树（M4）、图（M5）、哈希表（桶 + 链） | `rect`/`shape` + `connector` + `path` | **指针是箭头**（地址指向）；树/图必须有**根 / 入度节点** |
| **算法流程 / 伪代码图** | 开始 → 处理 → 判断分叉 → 循环回边 → 结束 | `shape`（flowChart 族 / `diamond`）+ `connector` | 菱形**必有分叉**；循环用**回边**；终止符圆角 |
| **编译流程** | 源码 → 词法 → 语法 → 语义 → 中间表示 → 优化 → 代码生成，旁边挂符号表 | `chevron` 或 `rect` 链 + 侧挂 `rect` | 侧挂**符号表 / 错误表**；每步给**输入输出** |
| **协议栈 / 网络分层** | 发送方 5 层 ↔ 接收方 5 层，层间**同行水平虚线**表「对等通信」 | 两列 `rect` + 水平 `connector` + 〔具象〕层内设备 | **对等层虚线水平**是关键；纵向层间实线为接口 |
| **时序图 / 状态机** | 竖生命线 + 横向消息箭头；状态机 = 圆节点 + 迁移箭头 + 条件标签 | `connector` + `shape`（初始 / 结束 / 判断）+ `rect`/圆 | 时序**自上而下按时间**；状态机**起始黑点 + 终止双圈** |
| **数据库 ER / 表关系** | 实体矩形（含字段）+ 关系菱形 / 连线 + 基数（1:N） | `rect` + `connector`（**无现成 ER 图形，自绘**） | **基数标注**（1、N）；主键下划线 |
| **UML 类图** | 三段矩形（类名 / 属性 / 方法）+ 继承（空心三角）/ 组合（实心菱形） | `shape` 三分栏空框 + 3 个 `text` 叠进分栏 + `connector` | 类名 / 属性 / 方法用 3 个独立 `text` 按 y=25% / 43.75% 叠进分栏；关系**符号要区分**（继承/组合/聚合/依赖） |
| **知识图谱 / 计算图** | 节点 + 有向带标签边（谓词） | 圆/`rect` + `connector` + 〔具象〕实体意象 | 边**必须带关系标签**；不同实体类型**不同形状** |
| **分布式共识 / 一致性** | 多节点 + 主从复制箭头 / 日志 | `can`/`rect` + `connector` + 〔具象〕节点意象 | 主节点**突出**；复制用**虚线** |

### B. 生物 / 医学 / 生命科学

| 图种 | 构成骨架 | 原语 | 关键细节 |
| --- | --- | --- | --- |
| **中心法则** | DNA →(转录) RNA →(翻译) 蛋白质，旁边画复制回环 | `path` 螺旋/链 + `connector` 箭头 + 〔具象〕DNA/RNA/蛋白 | **三个过程和两种分子**都要标；DNA 双链、RNA 单链 |
| **DNA 双螺旋** | 两条**反向平行**曲线 + 中间碱基对横档（A-T 双键、G-C 三键） | `path` 两条正弦 + 短横线 | **反向平行**（箭头方向相反）；碱基配对**数量不同**（2 vs 3 氢键） |
| **蛋白质结构** | 一级（链）→ 二级（α 螺旋 = 盘绕 / β 折叠 = 箭头片）→ 三级（球状折叠）→ 四级（多亚基） | `path` 螺旋（弹簧线）+ `shape:"rightArrow"` 作 β 片 | **α 螺旋画成弹簧、β 折叠画成带箭头片**（这是蛋白质图的「字形」）；四级用**不同颜色亚基**拼 |
| **细胞 / 细胞器** | 细胞膜（椭圆/不规则轮廓）+ 核（含核仁）+ 线粒体（双层 + 嵴）+ 内质网 + 高尔基 + 膜蛋白 | `path`（不规则轮廓最像）+ `shape:"circle"` + 内部 `path` | **各细胞器要有辨识特征**（线粒体双层+波浪嵴、高尔基层叠囊）；**膜双层**要画两道 |
| **细胞膜 / 磷脂双分子层** | 两层磷脂（头圆尾两条）夹中间 + 嵌入蛋白 + 通道 | `shape:"circle"` + 短线 + `path` 蛋白 | **头圆尾双尾**；疏水尾朝内 |
| **病毒结构** | 冠状病毒 = 圆 + 表面**刺突**（多枚）+ 内部 RNA；噬菌体 = 二十面体头 + 尾鞘 + 尾丝 | `shape:"circle"` + `path`/小`shape` 刺突 + `path` 尾丝 | **刺突要有多枚且均布**；噬菌体的**头/尾/尾丝三段**要分明；包膜病毒加**双层膜** |
| **信号通路** | 配体 → 受体 → 逐级激酶（磷酸化 P）→ 转录因子 → 入核 → 基因表达 | `connector` 链 + `shape` 节点；**抑制用 ⊣ 平头** | **抑制关系用「⊥」平头线**（不是箭头）；磷酸化加小 **P** 圆标；跨膜受体要有**膜** |
| **代谢通路 / 循环** | 底物 →（酶）中间物 → … → 产物；循环用 **M3** | 圆/`rect` 节点 + 箭头；**酶名标在线旁** | **酶标在箭头上**（不是节点里）；可逆反应用**双向箭头**；ATP/NADH 标辅因子 |
| **基因调控 / 操纵子** | 启动子 / 操纵基因 / 结构基因 排在一条 DNA 线上 + 调控蛋白结合 | `shape:"line"` 作 DNA + 分区 `rect` | **DNA 画成一条直线**，元件按**顺序排列**；结合用**蛋白块压在线段上** |
| **免疫应答 / 抗体** | 病原 → APC → T 细胞 → B 细胞 → 抗体（Y 形）；细胞因子虚线 | 细胞用圆/不规则 + 抗体 `path` **Y 形** | **抗体是 Y 形**；不同细胞**不同形状**；细胞因子用**虚线** |
| **解剖 / 器官** | 器官轮廓 + 分区 + 血管/神经 + 引线标注 | `path` 轮廓 + `connector` 引线 | **形状要像**（轮廓是关键）；标注**不交叉**；层次用**深浅** |
| **医学诊断路径** | 症状 → 检查 → 判断 → 分型治疗（**M2 决策树**） | `shape`（flowChart 族）+ `connector` | 判断**菱形分叉**；治疗分支**并列** |
| **药代 / 剂量-效应** | 血药浓度-时间曲线（M7）；剂量-响应 S 形曲线 | `chart:line` 或 `path` | 标 **Cmax/Tmax/AUC/半衰期**；S 曲线标 **IC50/EC50** |
| **实验流程 / 论文方法图** | 样本 → 处理 → 检测 → 分析（**M2**），配样品管/移液/仪器图形 | `shape`/`path` 器件 + `connector` | 每步给**样本量 / 试剂 / 条件** |
| **进化树 / 系统发育** | M4 树，枝长 = 差异，叶 = 物种 | `connector:elbow` + `text` | **枝长有意义**；有根树标**外群**；可加**时间尺度条** |
| **细胞周期 / 分裂** | 圆环分段（G1/S/G2/M）；有丝分裂分阶段图 | `shape:"donut"`/`blockArc` + 分阶段 `path` | 环形**顺时针**；分裂图**染色体形态**逐阶段变 |

| **通信拓扑** | 星形（中心交换机 + 放射）/ 环（周向）/ 总线（横轴 + 支线）/ 网状 / 树 | 〔具象〕网络设备图形 + `connector`（M5） | 节点**优先画具象设备图形**（交换机 / 路由器 / 云 / 服务器 / 终端），**别用空白矩形**；**中心节点突出**；链路**冗余用虚线**；标带宽/时延；超 12 节点**分组** |

| **网络/系统框图** | 信源 → 编码 → 调制 → 信道（加噪声）→ 解调 → 解码 → 信宿 | `rect` 链 + 噪声用**加号圆 ⨁** | **信道加噪声源**是信息论图的关键符号（⨁）；标信道增益 |
| **天线方向图** | 极坐标 + 主瓣旁瓣 | 极坐标轴 + `path` 玫瑰瓣曲线 | **主瓣朝主方向**；标**增益/波束宽度/旁瓣抑制** |

| **状态机 / FSM** | 状态圆 + 迁移箭头 + 输入/输出标签 | `connector` + `shape`（初始 / 结束 / 判断） | 标 `输入/输出`；起始态双圈 |
| **PCB / 芯片版图** | 板框 + 焊盘/走线/元件位号 + 层 | `rect`/`path` + `text` 位号 + 〔具象〕器件位号图形 | **标注位号 R1/U2**；走线正交或 45°；分层用颜色 |

## 三、高频图「可照做」详解（元素级）

> 这一节把最常画、最容易被画简陋的图拆到「元素 + 坐标」级。**默认画布 1280×720，留白 60。**

### 3.1 Transformer 架构图
- **构图**：整体**左→右**，编码器在左、解码器在右（只画编码器时右侧留「×N」）。
- **元素**（自左到右）：① 输入文本 `text` → ② 箭头 → ③ 「Input Embedding」`roundRect` → ④ **加号圆 ⨁** + 「Positional Encoding」小 `rect`（旁注）→ ⑤ 大 `rect` 包住「编码器块」→ 块内顺序：`Multi-Head Attention` → ⨁（残差汇入）→ `Layer Norm` → `Feed Forward` → ⨁ → `Layer Norm` → ⑥ 右侧**大括号 `path`** + `text:"×N"` → ⑦ 输出。
- **要点**：
  - **残差是绕过子块的另一条线**（从 ⨁ 左边绕到 ⨁ 右边），**绝不能只画一条直线**——这是最常见的「简陋」点。
  - **Q / K / V**：从注意力块输入处**分三叉**标 Q、K、V。
  - ⨁ 用 `shape:"circle"` + `text:"+"`，或用 `shape:"mathPlus"`。
  - 「×N」用**大括号 `path`**（`M…C…`）包住整块 + `text`。
  - 层内**同色系**：注意力一种色、FFN 一种色、Norm 灰色。
- **陷阱**：漏残差 / 漏位置编码 / 把「×N」写成文字堆在角上。

### 3.2 DNA 双螺旋
- **构图**：两条**正弦曲线**（`path`，周期 2–3 个），**相位相反**；中间每隔固定水平距离画**碱基对横线**；横线长度略短于两线间距。
- **要点**：两链**反向平行**（两端各加一个小箭头，方向相反）；A–T 用**双横线**、G–C 用**三横线**；配色：一链蓝、一链橙，碱基另色。
- **陷阱**：两链同向；碱基对不连线；周期太少（<2）看着像弧。

### 3.3 信号波形（时域）
- **构图**：坐标轴（**带箭头的 x/y 轴**，x 标 t、y 标 幅度）→ 波形 → 标振幅/周期。
- **要点**：正弦用 `path` 的**三次贝塞尔**平滑拼接，**至少 2.5 个周期**；方波用**阶梯折线**（垂直沿 + 水平段）；标 **T、A、Vpp、f**；可叠一条**虚线均值/阈值线**。
- **陷阱**：只画 1 个周期；轴无箭头无单位；正弦用多段圆弧导致不平滑。

### 3.4 细胞剖面
- **构图**：**不规则椭圆轮廓**（`path`，比正圆更像细胞）→ 细胞膜**双线** → 核（圆 + 核仁小圆）→ 线粒体（**胶囊形 + 内部波浪嵴**）→ 内质网（**弯曲条带 + 小点 = 核糖体**）→ 高尔基（**3–4 层叠弯曲囊**）→ 膜蛋白（嵌在膜上的块）。
- **要点**：**每个细胞器要有「辨识特征」**：线粒体双层 + 嵴、高尔基层叠、内质网带核糖体点；细胞质用**极浅底色**；标注用**引线**指向，不交叉。
- **陷阱**：细胞器全画成圆（无法区分）；膜画成单线。

### 3.5 电路：RC 低通滤波器
- **构图**：输入端 → 电阻（**锯齿折线** `path`）→ 输出节点 → 电容（**两条平行短线**）接地 → 输出。
- **要点**：**导线只走正交**（`connector route:"elbow"` 或水平/垂直 `shape:"line"`）；**连接点画实心圆点**；标 **R、C、Vin、Vout、GND**；GND 用**三条递减横线**符号。
- **陷阱**：电阻画成矩形（国际符号可，但要**统一**）；导线斜穿；无接地符号。

### 3.6 控制系统框图
- **构图**：给定 R → **⨁ 比较点**（标 + / −）→ 控制器 G_c(s) → 被控对象 G_p(s) → 输出 Y；**反馈支线** 从 Y 经 H(s) 回到 ⨁ 的 − 端。
- **要点**：**反馈必须闭环**；比较点用**加号圆**并标 **+ / −**；每条框内写**传递函数**；用 `connector` 正交走线、箭头表信号流向。
- **陷阱**：反馈断头；比较点不标正负；用直线斜连。

### 3.7 通信拓扑（星形 / 网状）
- **构图**：中心 = 交换机（**画具象设备图形**：`path` 自绘交换机 / 路由器轮廓，或 `cube` 意象）；外围 = N 个终端（**同样画具象图形**：台式机 / 笔记本 / 打印机 / 手机 / 终端的意象），**均布在圆周**；连线 = `connector` 直线。
- **要点**：中心**视觉权重**最大（放大、强调色）；链路**主/备线型区分**（实线/虚线）；标**带宽 / 时延**；>12 节点**用浅底框分组**。
- **陷阱**：中心与外围同大小；连线交叉混乱；**所有节点画成同一种空白圆角矩形**（一眼分不出路由器 / 交换机 / 防火墙——该画具象图形却没画）。

### 3.8 病毒（冠状病毒）
- **构图**：中心 `circle`（浅色，代表包膜/核衣壳）→ 内部一小段 **`path` 螺旋/折线**（RNA）→ 圆周边**均布 8–12 枚刺突**（`path` 或小 `shape`，**外伸**）。
- **要点**：刺突**数量够、分布均匀、形状一致**（这是「像」的关键）；包膜病毒画**双圈**；标注 S 蛋白 / RNA / 包膜。
- **陷阱**：刺突太少（2–3 个）→ 像太阳不像病毒；刺突长短不一。

### 3.9 分层堆栈（协议栈）
- **构图**：左侧发送端一列 5 个 `rect`（应用/传输/网络/数据链路/物理），右侧接收端**镜像**同 5 个；**同一层用水平虚线相连**；层内 `text` 写层名 + 协议（HTTP/TCP/IP/…）。
- **要点**：**对等层虚线水平**；**纵向层间实线为接口**；左右**严格对齐**；可在层右端画数据封装头（小色块）。
- **陷阱**：两侧层高不一致；对等线斜画。

### 3.10 供需曲线
- **构图**：轴（x = 数量 Q，y = 价格 P）→ 供给曲线（**上升**）→ 需求曲线（**下降**）→ 交点 **E**（标 Qe、Pe）。
- **要点**：两条曲线**都有箭头表方向**；标注**均衡点**；若画「移动」，用虚线原位置 + 实线新位置 + 箭头。
- **陷阱**：两曲线都上升/下降；无均衡点。
