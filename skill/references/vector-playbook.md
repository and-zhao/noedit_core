# 矢量绘图用法手册（PPT 创作）

**这份回答四件事**：① 核心到底有哪些矢量能力；② 什么时候用矢量；③ 每种能力用在哪些场景 / 哪些场景该用哪些能力；④ 怎么用才高级、一个 PPT 里该用多少。

> 落笔方式用 Python API 描述：`api.insert(path, element)`、`api.update(path, props, ...)`（点号路径）、`api.import_asset(path, [文件...])`、`api.export(path, "png"/"svg"/"pptx", ...)`；签名见 [api.md](api.md)。
> 与 [sci-vector-drawing.md](sci-vector-drawing.md) 分工：**那份是「科研图的硬规范（选型 / 统计量 / 投稿）」；这份是「矢量能力怎么在 PPT 里发挥」**。字段的唯一权威仍是 [element-schema.md](element-schema.md)。
> **要画具体领域的原理图（架构 / 流程 / 结构 / 通路 / 波形 / 拓扑）时，去 [diagram-atlas.md](diagram-atlas.md)**（跨领域原理图图谱：14 母题 + 领域图种库 + 元素级详解）。
> 与 [design-recipes.md](design-recipes.md) 分工：那边是「配色 / 版式 / 装饰配方」，本份是「矢量的用法与用量」。

## 一、能力全景：核心有哪些矢量能力

### 1.1 六类「矢量内容元素」（核心可直接写）

| 元素 | 一句话定位 | 关键事实（别踩） |
| --- | --- | --- |
| `shape` | **几何基元 / 预设图形**：容器、模块、箭头、流程节点、装置外壳 | **86 个 OOXML 预设**（见 1.3）；默认**无边框**（`borderWidth:0`），要描边必须显式写；填充只认 `style.background`（写 `fill` 无效）；**不承载文字** |
| `path` | **任意矢量轮廓 / 线稿**：曲线、螺旋、波形、通路、自定义符号 | 自写 `props.d`（`M/L/C/Q/A/Z`，**局部坐标 0..w / 0..h**）；默认无边框，线稿必须显式写 `borderWidth > 0`；**避免弧线 `A/a`**（PPTX 回退截图） |
| `connector` | **元素间连线**：流程链、有向关系、引线 | 端点写**元素名**（推荐）或坐标；`route`=straight/elbow/curve；**只用它画连线，不要拿 shape 的线/箭头拼** |
| `chart` | **20 种数据图**（含统计层：误差棒 / 显著性 / 拟合） | 数据来自 `props.rows`；PPTX 里默认映射成**原生 PPTX 图表**（可继续编辑） |
| `text` | **正文 / 标题 / 标签 / 公式** | PPTX 里是**逐行真文本**（可编辑）；公式写 `$…$` / `$$…$$` |
| `table` | **数据表 / 参数表** | PPTX 里是**原生表格**（可编辑） |

> 这六类在导出 PPTX 时**默认都写矢量**（可编辑）；`code` 也走「逐行真文本 + 图元重建」。

### 1.2 「样式」能力（叠在任意矢量元素上）

| 能力 | 字段 | 用在什么上 |
| --- | --- | --- |
| **渐变填充** | `props.fillType:"gradient"` + `fillGradientTo` / `fillGradientAngle` | 背景色带、色块氛围、强调块（**装饰用，别做主体**——会回退截图） |
| **描边三件套** | `style.borderWidth` / `borderColor` / `borderStyle` | 线稿感、模块框、强调轮廓（**只有宽度为真值时才输出**） |
| **线型** | `props.strokeDash`：solid/dash/longDash/dot/dashDot/roundDot | 虚线 = 次要 / 预测 / 抑制；点线 = 参考线；实线 = 主关系 |
| **线端 / 拐角** | `strokeCap`（butt/round/square）、`strokeJoin`（miter/round/bevel） | 圆头显柔和、方头显硬朗；圆角拐弯更「现代」 |
| **四角独立圆角** | `radiusTL/TR/BR/BL`（矩形族） | 「标签卡」「引用块」的不对称圆角（只圆上角） |
| **翻转 / 旋转** | `props.flipH/flipV`、`rotate` | 镜像箭头、对角装饰、斜置标签 |
| **阴影 / 发光 / 倒影** | `shadowOn` 族 / `glowOn` 族 / `reflectOn` 族 | 悬浮卡（轻阴影）、重点发光、立体倒影（**滥用会廉价且回退截图**） |
| **不透明度** | `opacity` / `fillOpacity` | 水印底纹、次要层、叠加氛围 |

### 1.3 核心没有的编辑器功能（**需自写 `props.d` / `props.shape`**）

- **86 个 `shape` 预设**（可直接写名字用：矩形族 9 / 基础几何 7 / 正多边形 6 / 立体环形 9 / 装饰 5 / 自然 8 / 星形 10 / 箭头 14 / 流程图 12 / 标注其它 6）——核心没有预设可视化面板，但可直接写 `props.shape` 名字；预设清单见 [element-schema.md](element-schema.md)，或运行时用 `api.element_types()` 拿。
- **布尔运算**：核心没有并集 / 差集 / 交集 / 排除。要复合轮廓，**自写 `props.d`** 用路径命令拼出来。
- **科研波形**：核心没有 sin/cos/gauss/lorentz/decay/damped/sigmoid/tanh/step/parabola/log/linear 波形预设。信号 / 响应 / 曲线要**自写 `props.d`**（`M/L/C/Q`，避免弧线 `A`）；选型参考 [sci-vector-drawing.md](sci-vector-drawing.md)。
- **绘制工具**：核心没有钢笔（折线 + 贝塞尔）/ 矩形 / 椭圆 / 节点编辑等交互工具。任意轮廓、手绘感形状全部**自写 `props.d`**。

> ⚠️ **给核心写指令时注意**：以上效果一律靠**自写 `props.shape` 名 / `props.d` 路径**实现，核心没有 UI 入口可调，**不要谎称能调用**。

> ✅ **核心内置矢量图标库**（1800+ 图标，36 组：draw.io 几何 / 流程 / 器件、Bioicons 分子 / 细胞 / 器材 / 动植物、Apollon UML / 流程图）。要具象图形，四条路：
> 1. **图标库直接插**（首选）：`api.icon_search("路由器")` 找 id → `api.icon_insert(path, id, x=, y=, size=120, color="#c0392b")`。单色图标插成**一个可编辑 `path`**（能换色）；多色图标插成 `group` 容器 + 分层成员。整组浏览用 `api.icon_groups()` / `api.icon_list(group)`。
> 2. **`shape` 预设**拼意象（云 / 箭头 / 六边形 / 星形…）；
> 3. **`path` 自绘**轮廓——图标库和预设都没有的，**当场画**，仍要具象，**不许退回空白矩形**；
> 4. 手头有**图标图片**再用 `api.import_asset(path, [文件...])` 导入，当 `image` 元素用。
>
> **触发规则（硬性）**：凡节点 / 部件代表**真实物件或领域标准符号**（网络设备 / 电子元件 / 化工设备 / 液压元件 / 分子细胞 / UML 图元 / 实验器材…），**一律先 `api.icon_search` 找图标插入**；图标库没有的，再按 `shape` 预设 / `path` 自绘具象图形来表现（或导入图片）。**把具象物件画成空白矩形，按缺陷算。**
> 全量「图标组 → 触发场景」对照表见 [sci-vector-drawing.md](sci-vector-drawing.md) 第 3.4 节，可据此判断该画什么、怎么画。

### 1.4 导出侧矢量能力

- **SVG**：真矢量（图形 / 路径 / 连线为矢量，其余按 dpi 内嵌）。
- **PPTX**：**默认矢量优先**——纯文字 / 图形 / 连线 / 原生图表 / 原生表格 / 代码 / 公式直接写矢量，可继续编辑。
- **PNG**：逐页位图，96–600 DPI，可透明（投稿默认 300）。
- **HTML / PDF**：真交互 / 印刷。

### 1.5 一句话记住：什么保矢量、什么会回退

| 保矢量（可编辑） | 回退成截图（丢可编辑性） |
| --- | --- |
| 纯色（含 `rgba()` 自带 alpha）/ 元素不透明 / 无投影无发光无倒影无渐变的 `shape`、`path`（无弧线）、`connector`、`text`、`table`、`chart`、`code`、公式 | 渐变 / 投影 / 发光 / **元素级**不透明度（`opacity` / `fillOpacity`）/ 模糊 / **`path` 弧线命令 `A`** |

> 颜色字符串自带的 `rgba()` alpha（如 `rgba(56,189,248,0.16)`）会连同元素 `opacity` 一起写成 OOXML 的 `a:alpha`，**保矢量、与画布像素一致**；只有元素级的 `opacity` / `fillOpacity` 才触发回退。

> **主体元素要可编辑 → 避开右列效果；装饰用了右列效果 → 无伤大雅。**

## 二、什么时候用矢量（决策准则）

**三问法**：能不能用「**图形 + 文字 + 连线**」摆出来？→ 能 → **用矢量**。

| 信号 | 决策 |
| --- | --- |
| 要表达**结构 / 关系 / 流程 / 层级 / 机制 / 数据** | **必须矢量** |
| 内容会**被反复修改**（配色、文案、位置） | **必须矢量**（改字段即可） |
| 要**放大不糊 / 打印 / 投稿** | **必须矢量** |
| 是**真实照片 / 仪器截图 / 外部渲染图** | 位图（`image`），图先落进工程 `assets/`（可导入本地图、也可用 agent 自带的生图 / 搜图，见 SKILL.md「图片策略」） |
| 是**静态讲不清的流转 / 扩散 / 爬升** | **用静态矢量表达**（箭头 / 序列 / 多帧并置）；微场景（`scene`）能进 HTML 与 PPTX（GIF），但**投屏 / 印刷件仍建议静态讲清，别硬凑** |
| 是**氛围纹理 / 真实质感底图** | 位图或纯色渐变，不必强上矢量 |

**两级优先**：**矢量原语 ＞ 位图（本地素材）**。**照片感**的配图可以用 agent 自带的生图 / 搜图，但**必须先落进工程 `assets/` 再引用 `relPath`**（见 SKILL.md「图片策略」第 2 档）；**结构图 / 原理图 / 流程图 / 装置图 / 数据图仍必须用矢量**，不许拿生图替代。

**该用矢量**：封面几何、目录、流程图、架构图、时间轴、对比图、机制图、通路图、装置图、数据图、图标、序号、角标、页眉页脚装饰、色带、进度、漏斗、雷达、比例尺、坐标示意、标注引线。
**不该硬用矢量**：写实照片、复杂纹理、超细颗粒（噪声/颗粒感）、大段无可视化的纯文字。

## 三、能力 → 场景（每种能力泛化到哪些场景）

### `shape`：几何基元
- **容器 / 分区**：卡片、面板、侧栏、底板层、区块背景（`rect` + 极浅底 + `borderRadius`）。
- **流程 / 结构**：`flowChartProcess`（处理）、`flowChartDecision`（判断）、`flowChartTerminator`（起止）、`flowChartDocument`（文档/输出）、`flowChartPredefinedProcess`（子过程）、`flowChartMagneticDisk`（数据）、`flowChartExtract`/`flowChartMerge`（分发/汇总）。
- **方向 / 关系**：`rightArrow`·`bentArrow`·`uturnArrow`（走向）、`chevron`（流程步骤带）、`leftRightArrow`（双向）。
- **层级 / 强调**：`star*`（星级/重点）、`plaque`（徽章）、`hexagon`（标签）、`diamond`（决策点）。
- **意象**：`cloud`（云/网络）、`moon`·`sun`（周期）、`lightningBolt`（能量/加速）、`heart`（健康）、`cross`·`mathPlus`（医疗/加号）。
- **立体 / 物理**：`cube`·`can`·`bevel`（3D 模块、容器、数据库）、`donut`·`blockArc`·`pie`·`chord`（环/弧/扇）。
- **标注**：`wedgeRectCallout`·`cloudCallout`（气泡讲解）。
- **线 / 弧**：`line`·`arc`（**必须显式写 `borderWidth`**）。

### `path`：任意轮廓
- **线稿图形**：螺旋、弹簧、势阱、装置剖面轮廓、自定义符号。
- **非标准形状**：布尔运算做不出、预设里没有的轮廓（团队自定义图形）。
- **曲线**：波形、衰减、S 形响应（**自写 `props.d`**）。
- **手绘感**：有机形状、不规则色块、涂鸦标注。
- **注意**：`path` 在 PPTX 里**默认走栅格化截图**；要「全矢量」时它不算保底元素，别把它当关键可编辑对象。

### `connector`：连线
- **一切有向关系**：流程链、依赖、调用、因果、反馈（虚线 + 平头 = 抑制）。
- **引线 / 标注线**：指向局部、拉出说明。
- **结构线**：时间轴主轴、树状分支（`route:"elbow"`）。
- **几何贴合**：端点绑元素名后，**线贴元素真实轮廓**、元素一动线自己跟着走。

### `chart`：数据图
- 比较 / 趋势 / 构成 / 分布 / 相关 / 多指标 / 矩阵（20 种选型见 [sci-vector-drawing.md](sci-vector-drawing.md) 2.1）。
- **统计层**：误差棒、显著性、拟合——「像研究」的关键。
- **仪表 / 进度**：KPI 页、完成度页、能力条。

### `text` / `table`
- `text`：所有文字与公式；**节点标签必须与 `shape` 分离，同坐标 + 居中**。
- `table`：参数表、实验结果、对比矩阵（**科研用三线表**）。

### 样式能力
- **渐变**：背景色带、氛围块、标题底衬（**装饰层**）。
- **虚线**：次要关系、预测、边界、禁用态。
- **四角圆角**：引用块 / 标签卡的不对称圆角。
- **阴影**：悬浮卡、浮层（**低透明度 + 大模糊**）。
- **倒影**：展台 / 陈列感（**慎用**）。
- **不透明度**：水印底纹、背景意象、次要层。

### 核心没有的编辑器能力（自绘替代）
- **布尔运算**：复合徽标、镂空图标、异形容器——核心无此功能，**自写 `props.d`**。
- **波形预设**：信号 / 响应 / 物理曲线——核心无预设，**自写 `props.d`**。
- **图标库**：核心**内置矢量图标库**——真实物件 / 标准符号先 `api.icon_search` 找、`api.icon_insert` 插成可编辑 `path`（多色则是 `group` + 成员）；图标库没有的再用 `shape` 预设 / `path` 自绘，或 `api.import_asset` 导入图片当 `image`；全量「图标组 → 触发场景」对照见 [sci-vector-drawing.md](sci-vector-drawing.md) 3.4 节。
- **绘制工具**：任意手绘形状——核心无交互绘制，**自写 `props.d`**。

## 四、场景 → 能力（场景索引表）

| 场景 | 首选能力 | 搭配（★=**具象物件：`shape` 预设 / `path` 自绘，或 `api.import_asset` 导入图片当 `image`**） | 注意 |
| --- | --- | --- | --- |
| 封面 | `shape` 几何 + `text` | ★具象意象图形 / `path` 线稿 / 渐变氛围 | 一页一个焦点，装饰不过三 |
| 目录 / 导航 | 序号 `shape`（圆/六边形）+ `text` + `connector` | ★小具象图形 / 预设符号 | 序号统一、等距 |
| 章节过渡 | 大号 `text` + 一个大 `shape`/`path` | 渐变底衬 | 信息量极低，靠尺寸说话 |
| 流程 / 步骤 | `shape`（flowChart 族）+ `text` + **`connector`** | ★`path`/`shape` 具象流程符号；`chevron` 步骤带 | **连线只用 connector**；节点 ≤ 12 |
| 架构 / 拓扑 | 分层 `rect` 容器 + **具象节点图形** + `connector` | ★网络设备图形（交换机 / 路由器 / 防火墙 / 云 / 服务器 / 终端）、机柜轮廓、组件 / 部署框、`cloud` 边界 | **节点是真实物件就用具象图形**；层次用底色深浅区分 |
| 时间轴 | `connector` 主轴 + `shape` 刻度点 + `text` | ★`shape`/`path` 强调图形 | 主轴一条线贯穿，别拼接 |
| 对比 / 优劣 | 两个 `roundRect` 对照区 + `text` | 双色 + ★勾叉图形（`path` 自绘） | 左右严格镜像对齐 |
| 原理 / 机制图 | `shape` + `path` + `connector` | ★**按领域自绘具象图形**（电子 / 液压 / 化工 / 生物 / UML，见 3.4 对照表） | 图形区 ≤ 65% 页宽，留说明区 |
| 实验装置 | `path` 轮廓 + **器件具象图形** + `connector` 引线 | ★实验器材 / 液压 / 机柜图形（自绘或导入）；`text` 标注 | 比例尺 / 单位不能少 |
| 电路 / 电子页 | 元件具象图形 + `connector` 正交导线 | ★电子元件符号（`path`/`shape` 自绘） | 元件符号规范；导线只走正交 |
| 化工 / 工艺页 | **P&ID 设备图形** + `connector` 管线 | ★工艺设备标准符号（`path`/`shape` 自绘） | 设备用标准符号；管线标流向 |
| 生物 / 医学页 | 细胞 / 分子 / 通路节点 | ★分子 / 基因 / 细胞 / 微生物 / 动植物图形（自绘或导入） | 各结构要有辨识特征 |
| 工业 / 机电页 | 器件具象图形 + `connector` | ★液压 / 机柜 / 价值流图形 | 符号统一 |
| 数据 / 算力页 | `chart` + 硬件 / 框架图形 | ★算力硬件图形（GPU / 工作站 / 框架…，自绘或导入） | 结论前置，图佐证 |
| 数据页 | `chart`（原生图表） | `text` 结论 | 结论前置，图佐证 |
| 多子图 / 面板拼版 | 多个 `chart` 或 `shape`+`path` 组合 | 编号 `text` + 浅底 `rect` 分组 | 同尺寸 / 同间距 / 同配色；编号用独立 `text`（第六节） |
| KPI / 进度 | `gauge` / `progress` | `shape` 底槽 | 一个强调色 |
| 图标点缀 | `shape` 预设 / `path` 线稿 | 导入图片 | 风格统一（全描边 或 全填充） |
| 页眉页脚 / 角标 | `shape:"line"` / 小矩形 / `arc` | 小图形 | 全篇每页统一摆放 |
| 引用 / 金句 | 不对称圆角 `shape` + `text` | `path` 引号 | 圆角只圆上角 |
| 分部封面 / 分隔 | 大 `shape` 色块 + `text` | 不透明度底纹 | 与全篇统一 |
| 结尾 / 致谢 | 同封面 | — | 首尾呼应 |

## 五、用在哪里：页面位置 × 矢量用法

| 位置 | 典型矢量用法 |
| --- | --- |
| **封面 / 封底** | 标题（`text`）+ 1~2 个大几何（`shape`/`path`）+ 可选渐变底衬；首尾同构 |
| **章节过渡页** | 超大编号 + 一个图形母题；信息极简 |
| **目录 / 导航** | 序号圆 + 短横线 + 小图形；等距排列 |
| **页眉 / 页脚** | 细线（`shape:"line"` 显式写宽度）、色块、页码角标、小三角；**全篇每页统一摆放** |
| **正文区** | 卡片 / 分栏背景（极浅底）、关键词高亮块、序号点 |
| **侧栏 / 边注** | 竖线 + 小 `shape` + `text`；不抢主内容 |
| **背景层** | 极淡几何底纹（大 `path` / `circle` + 低 `opacity`）、渐变色带 |
| **图表区** | `chart` 原生图表 + 结论 `text` |
| **示意图区** | `shape`+`path`+`connector` 组合 |
| **强调 / 装饰** | 星形、弧线、圆点、引线；**克制，一页 ≤ 3 处** |

## 六、多子图 / 面板拼版（一页多图怎么拼）

**是什么**：一页里并排 2 个以上图表 / 示意图，用统一编号 `(a)(b)(c)(d)` 组织，读起来是「一套图」。

**什么时候拼**

- 多组数据要**并列比较**（同一指标、不同处理 / 时间点 / 组别）。
- 一个结论需要**多个视角**：趋势（line）+ 分布（box/violin）+ 相关（scatter）+ 构成（bar）。
- 论文插图 / 答辩图版（2×2、1×3、1×2、2×3）。
- 主图里要放**局部放大**（inset）。

**四种子图关系**

| 关系 | 版式 | 要点 |
| --- | --- | --- |
| 并列（平权） | 1×2 / 1×3 / 2×2 / 2×3 | 各图**同尺寸、同权重** |
| 主从 | 大图 + 2~3 小图（右侧列 / L 形） | 主图约 2/3 宽，辅图一列 |
| 混合 | 如「上排 2 图 + 下排 1 宽图」 | 靠**栅格对齐**，别自由摆 |
| 局部放大 | 主图 + 放大框 + 引线 `connector` | 放大框与主图同配色；引线显式写宽度 |

**怎么拼（坐标几何）**

- 画布默认 **1280×720**；内容区建议**四周留白 60**，可用区约 **1160×600**。
- **面板同尺寸**：2×2 时每格 ≈ `(1160 − 40) / 2 = 560` 宽、`(600 − 40) / 2 = 280` 高；`gap` 全图统一（建议 **40**）。
- **对齐靠栅格**：所有面板的左 / 上边缘落在**同一组 x / y** 上，自己算好等距坐标，**不要目测**。
- **编号**：`(a)(b)(c)…` 位置全图统一（左上或右上角），**编号是独立 `text`**，不压在图上。
- **编号自己写**：核心没有「面板编号」一键功能，`(a)(b)(c)` 要**自己逐个加 `text` 元素**并对齐到当前几何。

**跨面板统一（「像一套图」的关键）**

- 尺寸 / 间距 / 四周留白**一致**。
- 配色 / 字号 / 线宽 / 图例样式**一致**：多个 `chart` 用**同一 `palettePreset`、同一 `fontSize`**。
- 统计口径一致（同一 `errorType` / `sigCorrect`）。
- 共享轴时**省略重复轴标**，在图注说明；**每块面板的小标题 / 单位不能省**。
- 不要在子图里各用一套标题样式 / 图例位置。

**与能力配合**

- 每块面板就是一个 `chart`（数据图）或 `shape`+`path`+`connector` 组合（示意图）。
- **常规图与统计图可混排**：经典 2×2 = 左上 `bar`（比较）+ 右上 `line`（趋势）+ 左下 `scatter`（相关）+ 右下 `box`（分布）。
- 子图之间的关系（箭头 / 分组框）用 `connector` 与浅底 `rect`，**别用图片拼**。

**常见坑**

- 各面板尺寸差 1~2px → 整体「发歪」；**务必用同一组 w/h**。
- 编号漏了 / 位置不统一 / 序号与阅读顺序不符。
- 各子图配色 / 字号不一致 → 不像一套。
- 面板间距不等 → 自己算好等距坐标统一。
- 一页子图 **> 6 个** → 焦点稀释，**拆页**。

**自检**：`[ ]` 编号齐且位置统一 `[ ]` 尺寸 / 间距 / 留白一致 `[ ]` 配色 / 字号 / 线宽一致 `[ ]` 共享轴有说明 `[ ]` 每图有单位 / 小标题 `[ ]` 一页 ≤ 6 子图

## 七、怎么用才显得高级

### 7.1 高级感 12 条

1. **克制**：一页 **一个视觉焦点**；配色 **一个强调色 + 中性灰阶**（语义色不过三）；装饰 **≤ 3 处**。
2. **线优先于面**：细描边（1~1.5px）线稿比厚重色块更「专业」；填色只用于必须强调处。
3. **用几何表达语义**：圆 = 阶段 / 状态，菱形 = 判断，箭头 = 流程，虚线 = 次要 / 预测——**图形语汇要一致**。
4. **全篇统一**：圆角半径、线宽、箭头大小、图标风格（全描边 or 全填充）、间距**一次性定死，全篇沿用**。
5. **对齐与栅格**：8px 栅格 + 左对齐轴 + 等距（自己算坐标），**散点式摆放最掉价**。
6. **层次三级**：面（浅底容器）→ 线（描边/连线）→ 点（强调色/圆点/星标）。
7. **轻阴影**：`shadowOn` 低透明度（0.1~0.2）+ 大模糊（16~32），**不要重投影**。
8. **渐变只做氛围**：用于背景 / 色带 / 底衬，**不做主体形状**（也避免回退截图）。
9. **留白**：四周 ≥ 24px，内容区不贴边；「空」是高级的前提。
10. **让数据说话**：数据页用 `chart` 而不是装饰性图形；图表要标结论、单位、显著性。
11. **同构呼应**：封面与封底、各章节过渡、卡片结构**同一套骨架**。
12. **首尾与转场统一**：全篇用同一个「图形母题」（一条线 / 一个圆 / 一种角），形成系列感。

### 7.2 反模式（矢量用错反而低级）

- 每个角都塞装饰 / emoji / 云朵，页面「花」而不「专」。
- 高饱和撞色、渐变滥用、重投影重发光（**又廉价又回退截图**）。
- 圆角、线宽、箭头样式**不统一**；图标半描边半填充。
- **把具象物件（路由器 / 泵阀 / 分子 / 细胞 / UML 类框…）画成空白矩形**——该用 `shape` 预设 / `path` 具象自绘（或导入图片）却偷懒，等于丢了「像」。
- **拿 `shape` 的直线 / 箭头去拼连线**（该用 `connector`）。
- **在 `shape` 上直接塞文字**（该 `shape` + `text` 同坐标分离）。
- 能矢量画的示意图却贴了位图。
- `path` 用了弧线命令 → 全页回退截图。
- 一页出现 4 种以上图形语汇（圆角卡 + 直角卡 + 六边形 + 气泡）。
- 线性趋势用饼图、占比用折线等**图表选型错**（见 [sci-vector-drawing.md](sci-vector-drawing.md) 2.1）。

## 八、篇幅策略：一个 PPT 用多少矢量

### 8.1 总原则

- **矢量是默认态，不是点缀**：能用图形表达的都矢量；**全篇 ≥ 60% 的页面应含矢量元素**。
- **纯文字页 ≤ 30%**（且尽量配一个图形焦点）。
- **数据页 / 原理页 = 100% 矢量**（`chart` 与 `shape+path+connector`）。
- **位图只出现在「必须是照片」处**，不做版面主体。
- **节奏**：每 3~5 页安排一个「**全矢量重页**」（机制图 / 大架构图 / 数据图），形成视觉呼吸，避免通篇平淡。

### 8.2 按页型的矢量用量配比

| 页型 | 矢量面积占比（建议） | 主要矢量用途 | 元素量级 |
| --- | --- | --- | --- |
| 封面 / 封底 | 20–35% | 标题 + 1~2 个大几何 + 底衬 | 3~8 |
| 章节过渡 | 30–50% | 大编号 / 大图形母题 | 2~6 |
| 目录 / 导航 | 40–60% | 序号 + 图形 + 分隔线 | 8~20 |
| 纯观点页 | 10–25% | 关键词块 + 1 个图形焦点 | 3~8 |
| 图文页 | 30–50% | 一张示意图 / 图形组 | 6~15 |
| 流程 / 时间轴 | 60–85% | 节点 + 连线 + 刻度 | 15~40 |
| 对比页 | 50–70% | 对照框 + 双色 + 图形 | 10~25 |
| 数据页 | 60–90% | 原生 `chart` + 结论 | 3~10 |
| 原理 / 机制页 | 70–100% | `shape`+`path`+`connector` 组合 | 20~60 |
| 结尾 / 致谢 | 20–40% | 呼应封面 | 3~8 |

> **元素量级**只是参考：**质量 > 数量**，宁少勿乱。原理页 20~60 个元素是「细节丰富」，超过要检查是否失去焦点。

### 8.3 硬指标自检

- [ ] 含矢量元素的页面 ≥ 60%
- [ ] 纯文字页 ≤ 30%
- [ ] 数据 / 原理页达到 100% 矢量
- [ ] 每 3~5 页有一个「全矢量重页」
- [ ] 全篇只有一个「图形母题」、一套圆角 / 线宽 / 箭头规则
- [ ] 一页装饰 ≤ 3 处、配色语义色 ≤ 3 种

## 九、落地检查清单

**画矢量页时的自检：**

- [ ] 判断对了吗：该矢量 / 该位图（三问法）
- [ ] 用对能力了吗（场景 → 能力索引表）
- [ ] **具象物件画具象了吗**：节点 / 部件是真实物件或标准符号，就用 `shape` 预设 / `path` 自绘具象图形（或 `api.import_asset` 导入图片），**别拿空白矩形糊弄**
- [ ] 连线用 `connector`（不是 shape 拼）；节点标签用独立 `text` 同坐标居中
- [ ] `shape` / `path` 线稿**显式写了 `borderWidth`**；填充写 `style.background`
- [ ] `path` 没用弧线 `A`；主体元素没沾渐变 / 投影 / 发光 / 元素级不透明度（`opacity` / `fillOpacity`）
- [ ] 全篇统一：圆角 / 线宽 / 箭头 / 图形风格 / 栅格 / 间距
- [ ] 留白 ≥ 24px；一页一个焦点；装饰 ≤ 3 处
- [ ] 配比达标（含矢量页 ≥ 60%、纯文字页 ≤ 30%）
- [ ] 首尾 / 转场用同一图形母题呼应
