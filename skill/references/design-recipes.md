# 设计参考

做 PPT 时把这份当词典查：术语怎么说、排版怎么定、风格怎么配、哪里最容易丑。

> 本核心**不带模板系统，但内置矢量图标库**：要图标先 `api.icon_search` 找、`api.icon_insert` 插成可编辑 `path`（多色是 `group` + 成员）；图标库没有的再用 `shape` 预设或 `path` 自绘，或把图标图片 `api.import_asset` 导入后当 `image` 用。**元素动画（`anim`）只在 HTML 导出里动**；**微场景（`scene`）HTML 一定动、PPTX 也能动**（核心自动抓帧合成 GIF 内嵌）。所以下面讲的「示意图一律静态矢量」仍是投屏 / 印刷的默认做法。

## 1. 术语表（写 prompt、描述需求时直接用这些词）

| 术语 | 含义 | 在画布里怎么落地 |
| --- | --- | --- |
| 出血 | 元素故意超出画布边缘 | 坐标给负数或超出 1280/720，导出时自动裁剪 |
| 安全区 | 内容不能被裁到的范围 | 文字统一留在左右 64 / 上下 48 以内 |
| 栅格 | 隐形的列与行 | 三列 `x = 64 / 456 / 848`，宽 368，间距 24 |
| 留白（负空间） | 元素之间的空 | 卡片间距 ≥ 24，页边距 64，宁可空不可挤 |
| 视觉层级 | 谁先被看到 | 靠字号（60 / 34 / 20 / 14）+ 颜色深浅 + 字重三级拉开 |
| 字重 | 粗细 | 只用 400 与 700 两档；层级靠字号，不靠粗细堆 |
| 字距 letterSpacing | 字之间的空 | 全大写英文标签加 1–2px 更精致；中文不加 |
| 行高 lineHeight | 行距倍数 | 标题 1.25–1.35，正文 1.7–1.8 |
| 亲密性 | 相关的靠得近 | 卡片标题与它的正文间距 8–12；卡片之间 24 |
| 对齐 | 边线齐 | 同一列所有元素左边界必须是同一个 x |
| 重复 | 同款元素反复出现 | 强调条、编号、页脚、页码全篇一致 |
| 对比 | 差异明显 | 深色底配浅字；不要 3 个相近的灰 |
| 主色 / 辅色 / 强调色 | 颜色分工 | 强调色**全页只用一处**（一个短线 / 一个数字） |
| 60-30-10 | 用色比例 | 60% 底色、30% 次色（卡片/图）、10% 强调 |
| 色阶 | 同色的深浅 | 图表、装饰圆、页码用主色的浅阶，画面更高级 |
| 卡片 | 内容容器 | `background: card` + 1px `line` 描边 + 圆角 16 + 轻投影 |
| 胶囊标签 | 圆头小标签 | rect 高 38、`borderRadius: 19`，内放 13px 字 |
| 投影层级 | 卡片浮起的程度 | `boxShadow: "0 10px 28px rgba(70,55,40,0.07)"`，宁轻勿重 |
| 分隔线 | 细线 | 高 1px 的 rect，颜色用 `line`，`borderWidth: 0` |
| 呼吸感 | 留白充足、不憋 | 标题上下各留 40 以上；卡片内边距 20 |
| 图标字 | 用字符当图标 | 序号 01/02、箭头、圆点字符，省去找图 |

## 2. 四条排版原则（CRAP）

| 原则 | 一句话 | 画布里怎么做到 |
| --- | --- | --- |
| 对比 Contrast | 不同就该明显不同 | 字号跨 2 档以上；深浅色差拉大；禁止「大一点点的字」 |
| 重复 Repetition | 同款元素反复用 | 每张卡都是同一个「强调条 + 编号 + 标题 + 正文」结构 |
| 对齐 Alignment | 边线同一个 x/y | 先定栅格，所有元素只允许落在列 x 上 |
| 亲密性 Proximity | 相关就近、无关就远 | 卡内间距 8–12，卡间 24，区块间 40+ |

## 3. 中文排版注意事项

- 中英混排时英文两侧留一个空格（视觉上更透气），如「NATURE NOTES · 2026」。
- 一行中文控制在 **18–26 字**，超过就换行或减字；长行阅读会掉。
- 正文字号不小于 **14px**；12–13px 只给图注、页脚、标签。
- 标题层级最多 2 级（主标题 + 卡片标题），再多就乱。
- 行高：正文 1.7–1.8，标题 1.25–1.35；行高小于 1.2 会挤，大于 2 会散。
- 不要用两端对齐（`textAlign: justify`），中文会拉出难看的字距。
- 标点不孤行：句末标点别单独占一行（用减字解决）。
- 数字用阿拉伯数字更清爽；对比数据统一单位与小数位。

## 6. 装饰手法清单（「好看」靠这些）

1. **色块**：低饱和圆/矩形压在角落，一半出界——比正放的形状高级。
2. **细线**：1px 分隔线 + 标题下方 5px 强调短线，全篇重复。
3. **编号**：`01 / 02 / 03` 用强调色，是全篇最省力的秩序感来源。
4. **胶囊标签**：圆角 19 的英文小标签，制造「专业感」。
5. **渐变**：用 `shape` 的 `props.fillType:"gradient"` + `props.fillGradientTo`（终止色）+ `props.fillGradientAngle`（角度）做章节页底色，比纯色耐看；**不要把 `linear-gradient()` 塞进 `style.background`**（该字段不认）。
6. **透明度**：`rgba()` 做压图遮罩、浅底块；比调浅色更自然。
7. **圆角一致**：卡片 16、图 10、胶囊 19、短条 3——同一套圆角只允许出现在对应角色上。
8. **重复制造节奏**：每页都有「页脚 + 页码 + 强调条」，翻页时视线有锚点。
9. **浅阶做装饰**：装饰圆、页码、水印字都用主色的浅阶，不抢正文。
10. **投影克制**：只给卡片加一层轻投影，其他元素一律不加。

## 7. 常见错误清单（改稿时优先查这些）

- 字号小于 12px；正文字号小于 14px。
- 正文超过 4 行（该拆卡或减字）。
- 主色超过 3 种；强调色一页出现好几次。
- 所有内容都居中，没有对齐线。
- 图片被拉伸变形（该用 `fit: cover` 而不是 `fill`）。
- 元素左边界各不相同，肉眼看出参差。
- 装饰压住正文（底板元素 z 序或位置不对）。
- 页与页风格不一致（换了色、换了圆角、页脚丢了）。
- 标题与正文同字号同字重，层级没拉开。
- 阴影过重（`0 10px 28px rgba(...,0.07)` 已够，别用 0.3）。
- 图表图例白写：单系列（`rows` 只有 2 列）或条目超过 12 条时，图例会被**自动隐藏**；要图例就备好 3 列以上的多系列数据，并控制在 12 条内。
- 代码块用 `lang:"text"` 或写了错的 `lang`（不做着色，等于白写）；深浅主题与页面底色不搭（`theme:"light"` 配深色页）。
- 表格没显式设 `rowBg` 却以为会透明（默认 `#ffffff` 白底）；暗底页忘了同时改 `headerBg` / `headerColor`。
- 页码缺失或位置每页不一样。

## 8. 代码块 / 表格 / 统计图 / 公式 的用法要点

这四类内容由核心的 `web/js/render-kit.js` 一份实现渲染，编辑器、网页导出、PPTX 的矢量贴图 / 回退截图四处一致。写元素时可以直接点名下面的字段。

### 8.1 代码块（CSDN / GitHub 风格，有真语法高亮）

- 想「像截图里那种代码框」就用：`{"type":"code","props":{"lang":"python","title":"train.py","theme":"dark","lineNumbers":true,"highlightLines":"12-14","shadow":true}}`。
- `lang` 支持二十多种（`python` `javascript` `typescript` `java` `kotlin` `c` `cpp` `csharp` `go` `rust` `php` `ruby` `swift` `sql` `html` `css` `json` `yaml` `markdown` `bash` `diff` `ini` `dockerfile` `makefile` `text`），写了就有配色。
- 亮点行用 `highlightLines:"3,5-7"`（配 `startLine` 可改起始行号）；标题栏可用 `title` + `langLabel`；圆点用 `macStyle`；想融入页面就 `showBar:false` + `shadow:false` + 自定义 `bgColor`/`fgColor`/`accent`。
- **没有复制按钮**（导出 PPTX 时默认走矢量，代码文字仍是可编辑真文本；要「可复制」就只能导出网页 HTML）。

### 8.2 表格（现在支持合并、列宽、逐列对齐、高亮）

- 基础：`rows` 二维数组，`header:true` 首行当表头。
- 精致：`aligns:["left","right","right"]` 逐列对齐；`columnWidths:["30%","35%","35%"]` 定列宽（写了就变 `table-layout:fixed`）；`density:"compact"` 压行高；`firstColBold:true` 让首列当行标题。
- 强调：`highlights:[[2,"*","#FFF3CD"]]` 整行底色、`[[3,1,"#DBEAFE"]]` 单格底色（**行列从 0 起**）。
- 合并：`merges:[[0,0,1,3]]` = 第 1 行整行合并（`[起始行,起始列,跨行,跨列]`，0 起算）。
- 表题：**表格没有 `caption` 字段**（PPTX 无此形式）——在表格正上方**另起一个 `text` 元素**写表题，`w` 与表格一致、`textAlign` 按需居中或左对齐。
- 暗色页必须同时给 `headerBg` / `headerColor` / `rowBg` / `borderColor`，否则默认是亮底黑字。
- **文字颜色按「衬底」定反差，不是按「页面底」**（实测踩过坑）：①页面 / 表格所在区域是**深色底（含黑）** → `headerColor` 与元素 `style.color` 都要给浅色，**绝不能是深色系**；②**白底** → 文字**只能**用深色系；③表格自带衬底色（`headerBg` / `altBg` / `rowBg` / `highlights` 单格）→ 文字颜色**跟那块衬底色做反差**。表身单元格默认不写颜色、继承元素 `style.color`，暗色页忘了给 = 看不见字。

### 8.3 统计图（20 种图，多系列自动上色）

- 选型：占比 → `pie`/`donut`；趋势 → `line`/`area`；对比 → `bar`/`hbar`；构成随时间 → `stackedArea`（或给柱 / 条加 `stacked:true` 堆叠）；多维评分 → `radar`；分布 → `box`/`violin`/`hist`/`ecdf`；相关 → `scatter`/`bubble`；转化 → `funnel`；单指标 → `gauge`/`progress`；层级对比 → `rose`；多指标矩阵 → `heatmap`；离散度 → `errorbar`。
- 多系列：`rows` 写成 `[["一月", 线上, 线下], …]`（3 列以上），每列一个系列自动取色；系列名用 `seriesNames:"线上,线下"`。**只有 2 列 = 单系列，图例不显示。**
- 常用调参：`grouped:true` 并排、`stacked:true` 堆叠、`colorByCategory:true` 按类目取色、`valueFormat:"thousand"|"percent"|"compact"` 数字格式、`showValues`/`showLegend`/`legendPos` 控制标注与图例、`maxValue` 固定轴上限。
- 环形：`kind:"donut"` + `innerRadius:0.6` + `centerText:"82%"`。
- 仪表盘：`kind:"gauge"` + `value:72` + `unit:"%"` + `gaugeMin/gaugeMax/gaugeTicks`。
- 配色：`palette` 给品牌色数组（纯色，不写渐变；写成逗号分隔的字符串也认）；暗底页要把 `titleColor` / `labelColor` / `valueColor` / `gridColor` / `axisColor` 一并改成浅色。

### 8.4 公式（只放在 text 元素里）

- 行内：`"text": "$E=mc^2$ 是本页的核心结论"`；独立居中：`"text": "$$ \\frac{a}{b} = c $$"`。
- 支持上下标、`\frac`、`\sqrt[n]{}`、`\sum_{i=1}^{n}`、希腊字母、关系符、`\underbrace{x+y}_{和}` / `\overbrace{a+b}^{n}`、`a\xrightarrow{n}b`、`\stackrel{\text{def}}{=}`、`\binom{n}{k}`、`\color{red}{X}`、`\begin{pmatrix}…\end{pmatrix}` / `cases` / `aligned` 等环境；**大括号用 `\big[` `\Big[` `\bigg[` `\Bigg[`（可带 `l`/`r`/`m` 后缀），不要指望 `\left`/`\right` 自动放大**；不支持 `\newcommand` 这类宏定义。
- 写公式时只用上面列出的命令：**未识别的命令会渲染成红色波浪线的 `\名字`**（例如漏了尺寸命令、写错命令名），一眼就能看出没渲染对。
- 含公式的 text 默认也走**矢量优先**（探针把图元清单摆回幻灯片，公式文字仍可编辑），保不住才回退截图，所以不会失真；`props.math:false` 可关掉解析、让 `$` 原样显示。

## 9. 示意图与关系图的构成（流程图 / 架构图 / 组合图）

前提事实：**`shape` 只画几何，不装文字**（只输出纯图形，没有 `text`）。所以「一个有字的节点」永远是**两个元素**：图形 + 独立文字元素。这一条决定了下面所有做法。

> 投屏 / 印刷件里示意图一律是静态矢量（`shape` / `path` / `connector` / `chart`），流转与方向靠节点顺序、虚线分支与箭头本身讲清——别指望动效（`anim` 只在 HTML 里成立；微场景虽能进 PPTX 动图，但结构图仍以静态讲清为准）。

### 9.1 通用铁律：图文分离 + 盒模型对齐

1. 节点 = `shape` + 一个 `text`，**两者的 `x` / `y` / `w` / `h` 完全一致**，文字写 `textAlign:"center"` + `verticalAlign:"middle"`。
   - 这样文字是按盒子居中，**不可能错位**；靠手调 `y` 去「找中线」必然错位。
   - `verticalAlign` 是面板兜底字段，**新元素不会自动写入**——不显式写就是顶对齐，这正是「字贴在图形上沿」的根因。
2. 两行以上的标签：保持 `w` 与图形相同，让浏览器自己换行居中；**不要**为了凑行数去改 `y`。
3. `lineHeight` 只写倍数（`1.2`–`1.6`）。写数值（如 `38`）会换算成超大行高，整块文字崩掉。
4. 图形本身要干净：`shape` **默认无边框**（`borderWidth:0`），直接写 `style.background` 就是纯色块；需要边框时再显式写 `style.borderWidth`（如 `1.5`）+ `borderColor`（填色写 **`style.background`**，写成 `fill` 会渲染成默认浅蓝）。
5. 一页里所有图形共用同一套圆角与描边宽度；层级只用「色 + 字号 + 留白」表达。

### 9.2 流程图

**节点图形（语义固定，同一张图里不许一个图形两种含义）**

| 语义 | `props.shape` |
| --- | --- |
| 处理 / 步骤 | `flowChartProcess`（或 `roundRect`） |
| 判断 / 分支 | `flowChartDecision`（或 `diamond`） |
| 起止 / 端点 | `flowChartTerminator` |
| 文档 / 产出 | `flowChartDocument` |
| 子流程 | `flowChartPredefinedProcess` |
| 数据存储 | `flowChartMagneticDisk`（或 `can`） |
| 离页 / 接续 | `flowChartOffpageConnector` |
| 分叉 / 合流 | `flowChartExtract`（一进多出） / `flowChartMerge`（多进一出） |

**连线（连接关系一律用 `connector` 元素，不要拿图形拼箭头）**

- 主链、分支、回流**全部用 `connector`**：两端写在 `props.from` / `props.to` 里，**写目标元素的 `name`**（节点元素一定要写 name，如「开始框」）——节点一动线自己跟着走。也可以写 `{"x": 绝对坐标, "y": 绝对坐标}` 做自由端点；**两端都不绑的线会退化成一个看不见的点**。
- `insert` 时 `connector` 的 `x / y / w / h` **不用自己算**（写 `0` 即可），落盘时按两端位置算出包围盒与路径；`arrowEndType` 默认 `triangle`（末端实心三角箭头）、`arrowStartType` 默认 `none`，两端可各自选 `none` / `triangle` 实心三角 / `hollowTriangle` 空心三角 / `open` 开放箭头 / `diamond` 实心菱形 / `hollowDiamond` 空心菱形 / `stealth` 燕尾（画 UML 关系图直接选：继承 = `hollowTriangle`、组合 = `diamond`、聚合 = `hollowDiamond`、依赖 = `open` + `strokeDash:"dash"`），`route` 取 `straight` 直线 / `elbow` 折线 / `curve` 曲线（**默认**，会出斜线）；想画正交折线必须显式写 `route:"elbow"`，`corner` 是折线圆角。
- 分支 / 异步 / 可选路径用 `props.strokeDash:"dash"` 画虚线，并在线的中点旁放一个「是 / 否」小标签 `text`；实线只表示主路径。
- 一个节点有多条出线时，用 `props.from.anchor` / `props.to.anchor` 指定出线边（`l` / `r` / `t` / `b` / `c` / `auto`），免得几条线叠在一起。
- 形状箭头（`chevron` 箭头带、`rightArrow` / `downArrow` / `bentArrow`）只在需要**粗箭头体块**做视觉引导时用，它不表达连接关系；拐弯的连线交给 `connector`，不要用 `bentArrow` 硬凑。

**做法顺序**：先定网格（列 `x`、行 `y`、统一 `w`/`h`）→ 摆节点图形（**每个节点都要写 `name`**）→ 贴同坐标标签 → 用 `connector` 连线（端点写节点 name）→ 最后用 `group` 打包。

**节点数**：一页 ≤ 12 个；超了就拆页，或把次要枝干压成一行小字。

**要「动感」的流程**：元素动画（`anim`）在 PPTX / PDF 里不播——节点依次点亮、光带沿路径流动这类效果只有导 HTML 才会跑（微场景虽能进 PPTX 成 GIF，但不适合承载流程讲解）。静态件改用矢量把流转讲清：节点按 `01 → 02 → 03` 编号排布、主路径实线 + 次要 / 可选路径虚线、`connector` 箭头指明方向；一张静态图讲不清的流转，就按步骤拆成多页。

### 9.3 架构图 / 分层图

1. **先分层，再放节点**：每层一个大 `rect`（`borderWidth:0` + 极浅底）当层容器，层名单起一个左对齐小字；层内节点一行排开。
2. 层高 > 层间距（例：层高 120、层间 24），「层」这件事才一眼可见。
3. 节点图形按 9.2 的语义表取，**同一含义全图统一**。
4. 连线：一律用 `connector`（端点写节点 `name`，`route:"elbow"` 自动走水平 / 垂直折线），同层横向、跨层纵向都由它搞定；只连必要的边（**连线数 ≤ 节点数 × 1.5**），其余靠层的包含关系暗示。
5. 强调：核心链路 `accent` 描边 + `glowOn:true`；非核心 `muted` 描边、`strokeDash:"dash"`。
6. 构图：图形区占页 ≤ 2/3，另一侧留文字说明区；不要满屏连线。

### 9.4 组合图（把一组元素当一个整体）

- 用 `group` 元素 + 子元素 `parentId`：子元素跟着组走，可整体移动 / 复制 / 对齐。
- 命名带前缀：`流程-登录` / `架构-接入层` / `图-时序`，后续批量改稿时按名匹配。
- 组本身没有渲染内容（不可见空盒子），组的 `w`/`h` 要与子元素外接框一致，否则选中框会跑偏。

### 9.5 关系图选型表

| 要讲的关系 | 怎么做 |
| --- | --- |
| 先后 / 里程碑 | 横向主轴 `line` + 交替上下节点 + 日期小字（时间轴） |
| 层级递进 | 底宽顶窄的 `trapezoid` 叠层（金字塔） |
| 逐步收窄 / 转化 | 等距 `trapezoid` 自上而下收窄（漏斗） |
| 循环 / 闭环 | 环形排布节点 + `arc` / `blockArc` 弧形箭头（循环图） |
| 同心包含 | 多个 `donut` / `blockArc` 同心叠放（洋葱圈） |
| 二维定位 | 十字轴 `line` + 象限浅底 `rect` + 标签定位（象限图） |
| 进度 / 排期 | 左标题列 + 多条等距 `line` + 右侧等长 `rect`（甘特条 / 进度条） |
| 平移映射 | 两列节点 + 水平连线，左右同色表示对应（映射关系） |

## 10. 统一视觉设计原则（做任何示意图都适用）

1. **图文绝不错位**：见 9.1。图形与文字分成两个元素，坐标尺寸完全一致 + 双向居中；两行以上是加宽文字框，不是挪 `y`。
2. **8px 栅格**：同排节点 `x` 全等、同层节点 `w`/`h` 全等；间距取 24 / 32 / 40；不要凭手感。
3. **配色不过三**：一张图最多 3 个语义色 + 中性色，全部从全篇 6 个色 token 里取；同色系靠深浅表达层级。**一个节点一个颜色 = 失败**。
4. **图形不单调，也不乱**：一张图至少出现 2–3 种图形语言（矩形 / 菱形 / 圆柱 / 起止 / 箭头），每种只表达一种含义。全是同一种矩形 = 单调；同图里图形语义重复 = 混乱。
5. **强调只用一种手段**：圆角、阴影、描边三者只选其一做强调，不要叠加；层级靠留白 + 三档字号（标题 20–24 / 节点 14–16 / 注释 11–12）。
6. **连线规范**：一律 1–1.5px；只走水平或垂直，**不画斜线**（`connector` 的 `route:"elbow"` 就是正交折线）；箭头大小与线宽匹配；交叉处错位让开，不重叠。
7. **对比度**：文字与底色对比 ≥ 4.5:1；暗底页上的表格 / 图表 / 图形描边都要显式改成浅色 token。
8. **留白即设计**：图形区占页 ≤ 65%，四周留 ≥ 24；宁可少放一个节点，也不要塞满。
9. **命名可检索**：`流程-xx` / `架构-层名` / `图-图注`，改稿时能按名定位。
10. **用静态矢量讲清流转**：静态画不清的流转、扩散、爬升，用分步节点 + 序号 + 虚线分支 + 箭头方向表达，必要时拆页分步；`anim` 只在导 HTML 时播放，别把它当默认假设。
